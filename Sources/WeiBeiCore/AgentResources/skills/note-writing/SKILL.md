# 笔记整理与修订

先辨明用户要“在对话里整理”“写进笔记”还是“改掉旧内容”。它们的内容可以相似，但写入结果不同。

## 核心流程

1. 依据用户指定材料或真实读取结果整理。针对旧笔记补充时，先读当前笔记，了解已有结构和内容；读取工具同样支持库内笔记。
2. 组织用户需要的定义、解释、例子、推导或结论。保留影响含义的前提、单位和来源；合并重复内容，避免把整段聊天原样搬入笔记。
3. 魏碑当前 `weibei_note_proposal` 向本轮目标笔记**追加内容**；没有目标笔记时由宿主在本轮课程新建。工具没有任选目标编号或原位替换参数，不能把读取其他笔记当成切换写入目标。
4. 用户明确要求写入时 `userRequested=true`；仅主动建议时为 false。`evidence` 使用实际材料、笔记或选区标签；缺少可用证据时保留整理稿并说明，不能造标签使提交通过。
5. 根据实际回执说明已保存、待采用或失败。不要把提交、动作编号或展示内容当作保存成功；重新生成或重试也不能把同一内容写两遍。

原位删除或替换旧笔记内容超出当前工具能力。先完成准确的修订稿，说明尚未替换；不能悄悄追加整份新版后声称完成了原位修订。

## 按需读取

用 `load_skill(id="note-writing", resource=...)`：

- 已有笔记的补充、纠错或修订请求，读[编辑范围与内容组织](references/editing.md)。
- 实际保存、保存冲突或关联材料，读[写入回执与关联](references/persistence.md)。
