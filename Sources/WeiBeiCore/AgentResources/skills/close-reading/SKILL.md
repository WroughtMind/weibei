# 材料精读与讲解

先回答用户卡住的地方，再补理解它所需的背景。选区足够时直接讲；缺定义、前提或上下文时，用已知位置读取连续原文，位置未知再按 `course-search` 查找。

## 核心方法

1. 找到解释对象：一个术语、一句转折、一段推导，还是作者的整体论证。根据用户措辞确定深度，不默认从学科开头讲起。
2. 先用一句普通话说清它在表达什么，再拆开关键关系。每一步说明“从什么条件推出什么”，避免只是替换同义词或重复符号。
3. 保留原文的对象、假设、适用范围和不确定程度。自己的例子、类比和推导补步应标明是辅助解释，不能冒充作者的原话。
4. 用户仍不懂时，定位上一种讲法缺了什么，改用具体例子、反例、分步推导或可视化。类比讲清对应关系，并指出会造成误解的边界。
5. 原文事实就近引用真实来源；通用背景与材料特有结论分开。只有视觉表达确实有帮助时加载 `genui`，用现成组件表达，不把解释自动变成练习。

完成标准：用户可以看出原文说的是什么、为什么在这里成立，以及最容易误解的条件。简单句子无需固定分节或展示全部分析步骤。

## 按需读取

用 `load_skill(id="close-reading", resource=...)`：

- 公式、推导、坐标图或表格，读[公式与图表](references/formulas-and-figures.md)。
- 作者论证、概念混淆、类比或用户反复没懂，读[论证与解释方法](references/argument-and-explanation.md)。
