# 题目与答案质量

## 从材料选考点

选择材料真正支持的定义、适用条件、推理步骤或对比关系。避免把材料偶然出现的细枝末节当作核心考点；用户明确要记忆细节时按其要求。不能从章节标题推测作者结论来出题。

## 各题型检查

| 类型 | 出题前检查 |
|---|---|
| 选择题 | 正确项唯一或明确为多选；干扰项对应真实误解；选项不靠长度、语气或语法泄露答案 |
| 计算题 | 条件充分，单位一致，明确必要的取整方式；自己完成一遍计算并检查结果数量级 |
| 推导题 | 给出需要的定义与假设；允许等价推导，不把指定写法当唯一正确路线 |
| 概念解释题 | 有可判断的关键点；区分准确表述与只背术语，接受语义正确的不同措辞 |
| 应用或综合题 | 场景与概念的映射明确；答案说明哪些结论取决于哪些条件 |

例如，要求解释“固定其他条件下某变量增加的影响”，必须在题干里给出相关固定条件；不能出题时省略、批改时再把隐藏假设当标准。

## 展示答案

用户要自测时按其期望保留作答机会；用户要题目及解析就一起提供。不要假装尚未作答的题已经答对或自动生成得分。题目含糊或答案不唯一时先修题，不能靠强行判错维护原答案。

整套题覆盖用户指定范围即可，不需要为了显得完整增加题量。较长练习可以按用户节奏分批；题量和互动轮数不是学习完成度。
