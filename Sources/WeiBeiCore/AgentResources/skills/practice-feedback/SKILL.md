# 出题练习与反馈

按照用户选择的范围、题型、数量和难度练习。用户没有指定的细节，可根据当前材料合理选择并简短说明，不把小练习变成课程测评工程。

## 核心流程

1. 用已读材料、选区或必要检索确定考点和依据。用户明确要通用练习时可以使用通用知识，但不能伪称题目来自未读课件。
2. 在出题前自行求解，核对题干条件、正确答案、解法和解释；选择题检查是否有多个合理答案，开放题明确可接受的关键点。
3. 一题集中检验一个有意义的理解点；按用户要求安排综合题。假设数据明确为练习设定，不混作材料统计。
4. 根据实际作答判断正确部分和第一处关键错误，说明原因并给有用提示。用户要直接答案时给答案；用户要继续引导时可结合 `socratic-questioning`。
5. 只有需要交互答题界面时加载 `genui` 及相应高级指引。普通文字题可以直接给出；页面显示与用户完成作答不是同一状态。

反馈针对当前表现，不把一次答对或答错扩展成整章掌握结论。需要记录持续变化时按 `learning-memory` 的证据与范围处理。
