# 魏碑回忆练习

## 触发场景

- 用户要求根据当前内容出题、考查或生成复习题。
- 用户希望逐题练习并核对答案。
- 用户要求从当前笔记找薄弱点或遗漏点。
- 用户提交答案，希望按当前证据判断正误。

## 工作流

1. 第一项动作必须调用 `weibei_context`，取得当前快照和 `contextRevision`。
2. 明确练习范围。用户指向选区时只考选区；否则按要求使用当前材料和当前笔记。
3. 只设计能由当前证据明确作答的问题。默认生成 5 题；用户指定数量或逐题模式时服从用户要求。
4. 题目覆盖回忆、解释、比较或基于原文的简单应用，但不得要求当前证据之外的知识。
5. 为每个标准答案准备来源标签。证据无法给出唯一答案的题目直接删除，不得凭常识补答案。
6. 用户提交答案后，重新读取当前上下文，再给出“正确 / 部分正确 / 当前证据无法确认”的判断与依据。

## 工具用法

- 只调用 `weibei_context`。
- 不调用 `weibei_note_proposal`；练习与反馈不得被描述为笔记写回。
- 修订号变化后重新生成或重新核对，不得沿用旧答案依据。

## 证据规则

- 事实依据只来自本轮快照中的 `material`、`note` 和 `selection`。
- `isTruncated: true` 时只能考查已返回片段，不得声称题目覆盖完整材料或完整笔记。
- `question` 与 `recentMessages` 只用于识别练习模式，不是答案证据。
- 标准答案使用 `[选区：标题]`、`[材料：标题]` 或 `[笔记：标题]` 标注来源。
- 不得引入外部知识，不得伪造概念定义、数字、例子、引文或来源位置。

## 输出格式

成套练习：

```markdown
## 练习
1. 题目
2. 题目

## 答案与依据
1. 标准答案。[材料：标题]
2. 标准答案。[笔记：标题]

## 当前未覆盖
只列出因证据不足而没有考查的内容。
```

逐题模式首次只输出：

```markdown
## 第 1 题
题目
```

收到用户答案后输出：

```markdown
## 判断
正确 / 部分正确 / 当前证据无法确认

## 依据
- [材料：标题] 核对说明。

## 下一题
下一道题目。
```

没有内容的章节省略。不得无依据扩展答案，也不得声称修改了用户笔记。
