# 魏碑回忆练习

## 触发场景

- 用户要求根据当前内容出题、考查或生成复习题。
- 用户希望逐题练习并核对答案。
- 用户要求从当前笔记找薄弱点或遗漏点。
- 用户提交答案，希望按当前证据判断正误。

## 工作流

1. 第一项动作必须调用 `weibei_context`，取得当前快照和 `contextRevision`。
2. 调用 `weibei_learning_memory`，优先看当前仍有效的困惑和待复习项。
3. 明确练习范围。用户指向选区时只考选区；否则按要求使用当前材料和当前笔记。
4. 只设计能由当前证据明确作答的问题。默认生成 5 题；用户指定数量或逐题模式时服从用户要求。
5. 题目覆盖回忆、解释、比较或基于原文的简单应用，但不得要求当前证据之外的知识。
6. 为每个标准答案准备来源标签。证据无法给出唯一答案的题目直接删除，不得凭常识补答案。
7. 用户提交答案后，重新读取当前上下文，再给出“正确 / 部分正确 / 当前证据无法确认”的判断与依据。只有表现足以支持长期判断时，才调用 `weibei_learning_update`记录理解或困惑。
8. 如果用户对某条活跃困惑完成了可核对的回忆或解释，可用 `resolutions` 和 `[会话：当前]` 依据提出结案建议。标签后必须逐字引用户本轮答案；仅仅看过标准答案、Agent 解释过，或单题蒙对，都不得提出结案。建议必须由用户在魏碑界面确认。

## 工具用法

- 先调用 `weibei_context`，再调用 `weibei_learning_memory`。
- 只在用户实际作答并产生可复用判断时调用 `weibei_learning_update`。
- 不调用 `weibei_note_proposal`；练习与反馈不得被描述为笔记写回。
- 修订号变化后重新生成或重新核对，不得沿用旧答案依据。

## 证据规则

- 事实依据只来自本轮快照中的 `material`、`note` 和 `selection`。
- `isTruncated: true` 时只能考查已返回片段，不得声称题目覆盖完整材料或完整笔记。
- `question` 与 `recentMessages` 只用于识别练习模式，不是答案证据。
- 标准答案使用 `[选区：标题]`、`[材料：标题]` 或 `[笔记：标题]` 标注来源。
- 不得引入外部知识，不得伪造概念定义、数字、例子、引文或来源位置。

## 回答方式

- 用户要“逐题考我”时，首次只问一题；收到作答后，用自然语言给出“正确 / 部分正确 / 当前证据无法确认”与就近来源，然后再问下一题。不必每轮都套固定标题。
- 用户要成套静态复习题时，可用编号列表，将答案放在题目后的独立折叠思路或后续回答中，不要一开始就让答案淹没题目。
- 用户明确要可点击测验、互动自测，或界面入口要求“可交互”时，默认生成一个 `weibei-interactive` 的 `quiz` 主研习面；需要多题时，在同一测验流程中逐题推进，不连续堆叠多个互动块。严格复用 `weibei-interactive-study` 中的 JSON 契约；解释和来源放在块内，不再额外复制一份静态“答案与依据”。
- 所有用到的精确跳转引用仍在回答末尾各自作为独立 `来源：...` 行，供魏碑生成来源附件。
- 只在确实有证据缺口且对用户有用时说明“当前未覆盖”，不输出空章节。
- 不得无依据扩展答案，也不得声称修改了用户笔记。
