# 课程资料检索

目标是取得能回答问题的原文及位置，而非把所有工具都调用一遍。

## 选择最短有效路径

- 已有足够的选区或工具原文：直接使用真实来源标签。
- 知道材料与页码或章节：`weibei_course_read` 直接读；PDF 页码从 1 开始，章节位置使用返回的完整标识。
- 只知道材料名：`weibei_course_map` 定位材料编号，再搜索或读取。
- 不知道出处：`weibei_search_workspace` 搜原文；从用户指定范围开始，需要时扩大到课程或资料库。当前课程是优先上下文，不是跨课程检索的许可门槛。

目录提供位置，没有正文证据。搜索返回的片段已经包含问题所需上下文时可直接引用；指代、定义、否定或推导不完整时读取附近连续正文。

## 关键用法

搜索匹配连续文字、忽略大小写，不拆词，也不是语义检索。不要把一整句自然语言问题当作必然能命中的查询。根据原文语言和术语换词；每次无结果后调整有依据的关键词或范围，避免重复相同查询。

`nextCursor` 表示还有结果，不代表每次都要耗尽。要回答“全文有没有”或列全所有材料时，才需要足够的覆盖证据。引用使用返回的标签，不用目录标题自造标签。

## 按需读取

用 `load_skill(id="course-search", resource=...)`：

- 找不到、跨语言、同义词或跨课程搜索时，读[查询与范围选择](references/query-strategy.md)。
- PDF 索引未完成、识别失败或需要判断全文覆盖时，读[覆盖范围与 PDF](references/coverage.md)。
