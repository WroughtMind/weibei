# 查询与范围选择

## 从问题变成可命中的原文词

将问题中的概念、原文短语、专名分别作为候选，不将多个词用空格拼成不存在的原文句子。使用短而有辨识度的词，再根据命中片段调整。

例如，用户问“资本积累为什么影响稳态”，当前资料是英文经济学课件：可以分别查 `steady state`、`capital accumulation`；若课件已出现 `steady-state`，采用实际拼写。不是把中文问题一次性送进工具后，凭零命中说材料没讲过。

命中太多时优先限定已知材料、选择更具体的短语，或按结果中的章节读取。符号、连字符、OCR 断行可能影响精确匹配；有这些迹象时尝试较短词或附近的章节标题。

## 确定范围

| 用户意图 | 优先范围 |
|---|---|
| “这一页／这份课件” | 已知位置直接读取；需搜索时 scope=material |
| “这门课哪一章” | scope=course，必要时先查课程目录 |
| “其他课／整个库有没有” | scope=library，再用命中结果定位材料 |
| 指名另一份材料 | 先从目录取得真实编号，不猜编号或凭当前材料替代 |

无结果只能说明这次查询在返回的覆盖范围没有命中。改词、改范围与读取已知位置是不同动作；根据缺口选择，不机械执行全部动作。

完成后给用户可点击的原文来源；“可能在某章”不能代替已经定位的结论。若仍没找到，交代查了什么范围和哪些关键缺口，而非把搜索过程完整倒给用户。
