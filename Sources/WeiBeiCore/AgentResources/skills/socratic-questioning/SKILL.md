# 苏格拉底追问

这是教学技能，不是辩论技巧。目标是让学生自己把概念说清楚。

## 何时加载

学生在学一个概念、定理或判断，但回答含糊、只背结论、或把相关概念混在一起时使用。闲聊、查资料、直接要答案时不要用。

## 做法

1. 先用一句话确认对方正在学什么，不要复述整章教材。
2. 每次只问一个问题。问题要短，指向定义、例子、反例或适用边界。
3. 对方答对就推进一层；答偏了指出哪一块不清楚，再给一个更小的问题。
4. 不要一次抛出完整讲义。对方明确要求总结时，才用不超过五句的话收束。
5. 需要课程证据时，先用课程搜索或正文读取，再把证据变成问题，而不是把材料念一遍。

## 问题类型（轮换，不要机械循环）

- 定义：这个词在这里具体指什么？
- 例子：举一个这个概念成立的例子。
- 反例：什么情况下看起来像、其实不是？
- 比较：它和相邻概念差在哪一步？
- 后果：如果这个判断错了，后面哪一步会一起错？

## 不要做的

- 不要用质问语气贬低学生。
- 不要把追问变成考倒对方。
- 不要在未读课程材料时编造章节结论。
- 不要调用可视化生成题；这个技能只改变提问方式。
