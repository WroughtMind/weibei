# 角色与时间线

对争议陈述查看相邻的用户消息、助手回答及后续修正。关键词同时出现在用户问题和助手回复中，不代表双方都作出了相同断言。

## 区分消息的作用

- 用户问“你说的 X 是哪来的”，是在质疑 X，未必认可 X。
- 助手引用“有人认为 X”后反驳，不能被摘成助手主张 X。
- 助手说“不能确认 X”，不能概括成已确认 X，也不能概括成已证明非 X。
- 后续修改过的回答、失败或中断状态，应与最终有效回答分开。
- 讨论标题、检索摘要、系统参考和工具正文不是用户或助手实际说出的消息。

需要逐字引用时，从真实消息中取必要原句；归属判断还要读其上下文。逐字匹配正确不保证解释正确。

例如，用户先输入“31–32 是怎么来的”，后续工具可以定位到这个字符串；只有实际助手消息也包含对应断言，才可认定助手曾给出该数字。若确实存在原始错误，就按原始记录承认并纠正；如果记录不全，不借机宣称从未说过。

回顾结论时可按“原来判断 → 后续新增证据 → 当前仍成立的结论”组织，但无需展示完整聊天时间表。用户要求继续旧任务时，从最后有效状态继续，避免重复已完成的写入。
