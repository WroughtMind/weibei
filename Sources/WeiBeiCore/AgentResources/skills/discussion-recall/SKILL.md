# 历史讨论回顾与纠错

把“讨论里出现过什么”和“这个说法是否正确”分开核对。旧回答是会话记录，不是事实来源。

## 核心流程

1. 根据用户给出的主题、材料或时间线，用 `weibei_find_discussions` 定位讨论；必要时扩大到 `allChats=true`。有真实聊天编号则直接读取。
2. 用 `weibei_read_discussion` 取得实际消息及后续追问、修正和状态。目录标题与摘要只用于定位；未完成回答不能说成最终结论。
3. 判断用户要的是逐字追溯、讨论总结、内容纠错，还是继续完成旧任务。按所需范围整理，不把所有聊天原样复述。
4. 按角色和时间核对关键陈述，区分用户的质疑、引用和助手的断言。存在多个版本时说明后续修正后仍有效的结论。
5. 若需判断结论真假，再读取材料或查公开来源。确认错误时改正具体内容和受影响的结论；无法确认时说明缺失证据，不给出未经核实的新解释。

引用使用讨论工具返回的标签，让用户能回到对应记录。没有找到某段记录，只能报告当前取得的范围，不能据此断言用户记错。

## 按需读取

用 `load_skill(id="discussion-recall", resource=...)`：

- “你刚才说过……”、引文归属或不同版本争议，读[角色与时间线](references/attribution.md)。
- 已有答案被质疑、前后矛盾或需要撤回结论，读[纠错与结论更新](references/correction.md)。
