# 长页面与缺失内容

`maximumCharacters` 是单次返回额度，不是整页长度。`nextCursor` 必须按返回值原样传给同一 URL，不将它当作页码或重新拼接地址。网页工具要求续读至游标为空；中途错误时不要把局部读取描述成“阅读全文”。

## 阅读中保留结构

长文章边读边保留与问题有关的章节、主张、依据和限定条件，不把每批正文都重复概括给用户。完成后统一组织答案。页面内部大量重复导航不等于多个独立证据。

如果用户要整篇摘要，而正文只有开头，应继续取得剩余部分；确实拿不到时明确摘要覆盖的部分。用户问局部事实，也不能在未读范围上作“文章没有提到”的否定结论。

## 提取失败的不同情况

| 观察 | 下一步 |
|---|---|
| 提取结果只有标题、菜单或登录说明 | 说明正文尚未取得；有实际链接时读可公开访问版本，或用公开标题检索原始发布页 |
| 表格行列被压平，无法确认数字所属对象 | 补找同一来源的可读表格或原始数据；不能按数字出现顺序自行猜列 |
| 引用了图表，但没有图像或可读数据 | 只使用文字明确给出的内容；魏碑当前材料图像工具不能读取任意远程网页图片 |
| 访问被拒绝或来源不在本轮许可集合 | 使用本轮原生搜索重新取得该公开来源，或如实说明；不绕过网络限制 |
| 链接打开的是不同版本或转载 | 核对标题、日期和内容差异，在回答中采用实际读取的版本 |

已经确认的读取障碍不应触发无休止重试。告诉用户缺了哪部分，以及这会限制哪项判断；能回答的部分正常回答。
