# 摘录与证据对应

先找到陈述的完整语境，再决定引用哪一句。搜索词命中、逐字引文匹配或来自权威域名，都不能单独证明解释正确。

## 检查对应关系

1. 谁说的：作者观点、作者转述、被反驳的说法、读者评论，不能互换。
2. 说了什么：区分事实、假设、预测、示例与条件结论；保留“仅在”“尚未”“不包括”等限制。
3. 指向谁：代词、表格行、引语主语必须与回答里的对象一致。
4. 支持多大范围：局部案例不能直接支持普遍结论；相关关系不能直接写成因果关系。

## 表格与精确数字

取得标题、行列标签、单位、统计时段和脚注后再引用。总计、分项、平均数和百分比可能在相邻列；空白、破折号和未统计不等于零。页面写“截至 8 月”，不能换成“截至今天”。自行计算时清楚区分来源给出的数值与计算结果。

## 摘录与转述

直接引语只摘取必要长度，并遵守适用的引用限制；不能改字后仍加引号。解释引语时说明它证明的具体事项。自己的概括或推断采用转述，不冒充逐字原文。

例如，原文“没有充分证据证明 A 导致 B”，不能被引用来支持“A 不会导致 B”。前者谈证据不足，后者是更强的否定判断。

完成前检查：去掉链接后，回答是否仍比原文说得更强？如果是，补足证据或收窄措辞；增加更多同类链接无法修复语义不对应。
