# 多材料比较与综合

围绕用户的问题组织材料，不按检索到的顺序堆摘要。

## 核心流程

1. 确定要比较的维度：定义、假设、机制、证据、结果或适用场景。优先用户指定的维度；必要时说明采用的比较标准。
2. 为每份材料取得相关原文及真实标签，网页用实际链接。只有标题或旧摘要时先补读；已有充分原文则直接使用，不重复读取。
3. 在内部建立“结论—来源—条件”的对应关系。分清资料明确说了什么、资料未讨论什么、自己推导出什么。某来源没有提及，不等于它反对该观点。
4. 先对齐术语、时期、单位、对象和假设，再判断一致或矛盾。冲突涉及核心结论时回到原文查限定条件；找不到依据时保留分歧，不强行统一。
5. 回答按共同问题展开，引用分别支持对应来源的观点。最终综合说明共同点、实质差异，以及这些差异会怎样影响用户的判断。

比较表适合共同维度明确的内容；复杂论证用自然段说明。不要为了填满表格补造缺项，也不以来源数量投票决定真伪。
