# 分歧与可比性

先判断分歧属于哪一类，再选择核对方式：

| 分歧 | 需要核对 |
|---|---|
| 同词不同义 | 两篇的明确定义与上下文；先解释含义再比较 |
| 不同假设下结论不同 | 哪些变量固定，短期或长期，模型是否封闭，成立条件如何变化 |
| 相同指标数字不同 | 对象、时点、单位、样本、数据版本和计算方式 |
| 证据力度不同 | 原始研究、综述、评论、教材示例分别支持什么范围 |
| 后续更正或版本变化 | 原版本与更新版的实际差异，以及用户问的是哪个时点 |
| 同样条件下实质相反 | 保留双方证据；说明尚未解决的争点，不把它说成仅仅措辞不同 |

例如，两份经济学材料对政策效果的描述不同，一份讨论短期固定价格，另一份讨论长期价格调整：可解释假设差异如何产生结论差异，不能在未读假设时说“其中一篇错了”，也不能自动宣称两者完全兼容。

跨来源统计比较按 `web-research` 的统计参考处理；比较已有课程原文不因此自动联网。需要额外公开事实才能判断时，再查相应外部来源，并与课程材料证据分开。

当核心定义或样本范围没有取得时，明确这项比较尚不成立；已经能够比较的其他维度仍可保留。不是每个冲突都需要最终裁决。
