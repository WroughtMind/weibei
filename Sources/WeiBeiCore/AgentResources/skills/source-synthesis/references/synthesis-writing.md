# 综合写作与联系

先决定交付物：用户要快速对比、回答一个问题、整理研究脉络，还是写成笔记。深度和结构跟随交付物，不把所有任务都写成研究报告。

## 从摘录到综合

1. 对每个主要问题保留必要的来源证据及限定条件。
2. 找出材料共同解释的关系，再指出它们各自增加、限制或挑战了哪一部分。
3. 对自己的新联系说明推理桥梁：哪些原文支持前提，连接这些前提还用了什么假设。
4. 把无法判断的部分留作明确问题，而不是写成已经成立的知识网络。

例如，笔记讨论储蓄、另一份材料讨论投资，不能仅凭词语相关就宣称两者给出了同一套因果解释。需要说明共同的变量、条件以及原文真正建立的关系。

## 输出质量

- 每段解决一个共同问题，不逐篇重复全文摘要。
- 不把“材料甲认为……”和“事实已证实……”混用。
- 对比表空缺写未讨论或未取得，避免用猜测补齐。
- 结论的强度不超过最关键证据；没有统一排名标准时按维度给比较。
- 引用放在具体观点旁，不能把一串来源放在段尾让用户猜它们支持什么。

用户要求保存时再按 `note-writing` 提交。讨论中的概念联系可以直接解释；魏碑关系工具只支持已落库笔记与课程材料的关联，不能把综合分析伪装成已经建立了任意知识图谱边。
