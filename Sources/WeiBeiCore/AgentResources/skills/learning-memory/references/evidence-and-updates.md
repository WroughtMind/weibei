# 记录依据与更新

## 先判断证据支持什么

| 实际证据 | 可以记录 | 不能直接推出 |
|---|---|---|
| 阅读位置停在第 12 页 | 当前读到第 12 页 | 已学完前 12 页、已掌握内容 |
| 用户明确说“这个概念我已经理解” | 课程知识档案中的用户自述 | 经独立考核确认掌握 |
| 用户正确解释或应用一个条件 | 本次可观察的具体表现 | 整章全部掌握 |
| 反复在同一条件上出错，或明确说一直卡住 | 有证据的具体困惑 | 一次普通提问就认定长期薄弱 |
| 用户明确持续目标或反复稳定偏好 | 对应目标或偏好 | 一次临时格式要求变成长期偏好 |
| 助手刚完成讲解 | 当前对话发生了讲解 | 用户已经理解 |

## 选择记录位置

自述掌握程度写课程知识档案：`kind=concept`，`text` 以“用户自述：”起头，`checkpoint=userRequested`，用 `weibei_course_profile_update`。目标、困惑、进度、偏好和可观察表现用学习记忆工具；不为同一事实同时写两份。

来源类型描述证据性质，不描述确信程度。推断只能标 `agentInference`，不能换成 `userStatement`；逐字证据须来自真实用户消息或实际读到的来源，不能引助手自己的教学内容证明用户学会。

## 更新已有记录

先读取，用返回的短别名更新原条目，新建时省略别名；不要把持久编号或标题猜成别名。现有条目仍准确时无需重写。用户后来解决了同一困惑，应反映状态变化，而非不断追加互相冲突的“仍不懂”“已理解”。

尊重工具返回的版本、可写字段和范围。发生状态变化或保存失败时重新读取并核对，不能假称记住，也不通过换编号绕过校验。每次只记录这次证据直接支持的变化。
