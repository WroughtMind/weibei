# 学习记忆与进度回顾

记忆帮助衔接学习和调整解释方式。材料内容仍从材料取得；长期记忆不承担知识库摘要的职责。

## 核心流程

1. 用户询问上次位置、进度、困惑或下一步时，调用 `weibei_read_learning_memory`。需要具体旧问答时另用 `discussion-recall`，不要根据记忆摘要编造对话。
2. 按记录实际支持的范围回答。阅读位置只说明读到哪里；用户自述和观察到的作答表现分别表述，不能写成确定的整体掌握判断。
3. 在系统规定的有意义学习节点，判断是否出现可长期复用的新变化。要更新先读已有条目，避免重复；普通问答无需每轮写记忆。
4. 用户明确自述某概念的掌握程度，写 `weibei_course_profile_update`，条目按“用户自述：…”记录。目标、困惑、偏好、阅读位置和实际作答表现写 `weibei_update_learning_memory`；同一事实只写一处。
5. 使用实际用户消息或已读来源的证据标签与逐字摘录，并正确区分 `userStatement`、`observed` 和 `agentInference`。按回执判断是否持久化；证据不够就留在当前对话。

正常学习记忆写入沿用系统授权，不增加逐条确认。也不为展示自己“记住了”而打断用户或主动安排固定学习计划。

## 按需读取

用 `load_skill(id="learning-memory", resource=...)`：

- 判断一条内容是否值得保存、应写哪里、如何更新时，读[记录依据与更新](references/evidence-and-updates.md)。
- 回顾上次状态、处理旧记忆与当前情况不一致时，读[衔接与过期记录](references/recall.md)。
