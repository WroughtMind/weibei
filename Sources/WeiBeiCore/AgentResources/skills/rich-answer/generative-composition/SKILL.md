# 生成式组合

只有 `weibei_ui_catalog` 显示专业渲染器和成熟深组件都不贴合，而互动仍明显帮助理解时，才使用受限 OpenUI、HTML 或通用组合能力。

- 从知识对象、关系和状态出发，不从卡片、网格、时间线等排版组件出发。
- 使用最小必要的视觉、控件和读数；多个协调控件允许存在，但必须服务同一学习目标。
- 关键条件、方向、变量和当前状态要与实际对象绑定，不能只在正文解释；来源说明由 Agent 自行判断，不参与组合能力准入。
- 不用低级点线重画标准图表、函数、分子结构、地图、图像叠层或三维；不生成任意脚本、外链、iframe、复杂 SVG 路径或像素布局。
- 结果必须是回答中的透明内联体验，不得重新生成一张带页头和导航的完整网页。

若组合后仍不能保证专业正确、完整显示或真实互动，回到正文并诚实说明当前能力边界。
