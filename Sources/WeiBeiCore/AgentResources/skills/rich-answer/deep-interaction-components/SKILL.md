# 深交互组件

已有深组件是成熟能力和质量参考，不是按题号套用的封闭模板。逐个比较它的通用性、来源诚实性和独特联动价值。

- 它提供专业渲染器没有的实验机制、刷选、步骤状态、证据阅读或多读数联动。
- 数据、参数和初始状态可由当前材料真实给出，不依赖组件内部固定题目数字。
- 放进回答流后仍透明、响应式、紧凑，不出现页头、标签页或独立小网站结构。
- 控件改变的正是用户要理解的图形、读数或知识状态。

不因为组件旧就淘汰，也不因为代码存在就长期平级暴露。题目专属实现应逐步拆成通用能力、专业渲染器、组合参考或高质量示例；用户已认可的效果与深联动不能回退。
