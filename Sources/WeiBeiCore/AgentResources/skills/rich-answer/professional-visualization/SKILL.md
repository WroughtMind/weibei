# 专业可视化

先描述知识对象、数据语义、坐标系、精度、计算、素材和互动目标，再读取 `weibei_ui_catalog`。目录是能力与参数的唯一真相；本 Skill 不替目录定义组件。

- 标准折线、柱状、面积、散点、直方、分布和组合图优先比较成熟图表能力，不让模型低级重画坐标与图例。
- 成对观测、拟合线、残差或协方差贡献这类“数值关系 + 对照”任务，先把标准散点/折线/柱状表达与二维几何实验对称比较；若标准图表已经清楚承载数据语义，就不要用几何对象重画统计图。
- 数学函数提交受限表达式、定义域、参数与探针目标，由专业能力负责采样、间断切段和设备像素比。
- 二维几何与确定性实验提交对象、约束、状态、轨迹和协调控件；三维提交空间对象、相机、图层、切片与学习目标。比较多个空间结构时，只有目录确认支持后才提交共享对象、状态快照和联动读数，不做装饰性三维。
- 地图与图像观察必须使用当前真实素材、正确坐标映射、共享显隐绑定和可读标注；`weibei_context.visualInspection.availableAssetIDs` 包含当前材料时，先调用 `weibei_visual_asset` 观察真实像素，再规划路线、区域、比例或构图叠层，不能只凭材料文字猜坐标，也不能脱离原图凭空重画。
- Python、Matplotlib、Bokeh、Panel、Pyodide 等只能通过目录实际返回的受控适配器参与计算、规格、静态产物或互动；不得生成任意代码绕过目录。当前目录返回 `weibei_compute_artifact` 时，只可用它执行固定统计、线性回归、分箱或受限函数采样，并把带哈希和来源的产物交给专业渲染器，不直接展示 Python 代码。

专业渲染器不是硬路由。若成熟深组件提供更强联动，可以选择它；若能力不足，诚实保留文本或再规划，不用低级点线伪装完成。
