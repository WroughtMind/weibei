# 魏碑 · Catalyst 会话实验

这是 #452 的独立会话候选，使用真正的 **Mac Catalyst、UIKit UICollectionView、MarkdownView / Litext UIKit 正文**。它不连接正式魏碑资料库、Keychain 或模型服务。输入会进入真实会话，然后触发有明确标记的固定事件重放；不会冒充模型回答。

应用窗口包含会话、输入区、来源材料、可编辑的实验笔记。笔记和卡片草稿保存在本次运行的内存中；关闭应用会结束这次实验数据。只有性能及行为记录写入独立应用目录。

## 构建和体验

从仓库根目录执行：

```sh
cd Experiments/CatalystChatLab
./script/build.sh
```

脚本通过 Xcode 的共享 scheme `CatalystChatLab`，在 `platform=macOS,variant=Mac Catalyst,arch=arm64` 目的地构建 Release。项目同时构建 arm64、x86_64；这不代表已经完成 Intel 实机体验。应用使用 Mac idiom（最终 `UIDeviceFamily = [6]`），独立 Bundle ID `org.weibei.CatalystChatLab`，最低系统由 Xcode 映射为 macOS 13。

输出：`dist/魏碑-Catalyst会话实验.app` 和保留应用权限、签名的同名 zip。这是本地 ad-hoc 签名候选，没有正式签名、公证或 Release。构建缓存只在本目录 `.build/`；不改正式构建编号、安装路径或发布流程。

Xcode 项目和共享 scheme 已入库，可直接打开；`project.yml` 是项目描述，修改文件清单时用 `xcodegen generate` 更新项目。应用包中的 `LabSourceRevision`、`LabSourceDirty` 记录构建提交和工作树状态。

Agent 操作真实窗口必须使用画中画。本地可在“样本与验证”菜单运行检查；`script/check-ci.sh` 只在 CI 的独立桌面运行，不能用它绕过本机桌面规则。

## 已实现的会话路径

| 内容 | 实际行为 |
| --- | --- |
| 长历史 | 首批 240 条合成历史，加一条完整富内容回答；每次前插 80 条，最多访问 720 条历史 |
| 单条长回答 | 一条回答包含 140 节正文、公式、代码、表格、图片、卡片和关系图；不截断、不默认折叠 |
| 固定流式 | 每 70 毫秒提交最多 24 个完整字符，完整解析处理后文引用变化，定向更新改变的块；可以停止并保留收到的内容 |
| 阅读位置 | 会话控制器统一协调前插、内容增高、改宽和追随最新；锚点包含消息、正文位置和视口偏移 |
| 选择与消息动作 | Litext 鼠标选择，跨段选区由会话层保留；复制、引用到输入框、查看来源；⌘回车发送、⌘L 聚焦输入 |
| 代码和表格 | 使用上游真实控件、高亮和横向滚动，不转截图；整条复制保留原始 Markdown |
| 公式和图片 | SwiftMath 原始数学资源；图片独立异步解码、保留实际比例。默认图片为实验自建 PNG |
| 来源和 wiki | 内部来源链接打开材料；双中括号笔记链接打开实验笔记 |
| 摘记卡 | `genui` 围栏接受明确的 `title`、`prompt` JSON；可编辑、折叠并收录到实验笔记。不是完整生产 GenUI 协议 |
| 关系图 | `mermaid` 围栏使用锁定的离线 Mermaid 11.12.0，在独立 WKWebView 内真实渲染 |
| 工作区 | 来源选字进入提问、编辑笔记、卡片收录、拖动分栏；状态不写入生产存储 |

普通正文先由 MarkdownView 生成属性文字，适合独立保存的正文、列表和公式由 Litext 直接显示。准备结果保留解析树、属性文字、CoreText 排版及尺寸；离屏 UIView 有界复用。需要实际子控件的代码、表格、图片和引用块继续由 MarkdownView 显示，不把它们改成纯文字。

消息是 UICollectionView 的逻辑 section，正文块是内部可复用 item。标题和动作只出现一次；块不是新建的假消息。停止、完成不会把分块正文重新合并或清空重建。跨段复制按完整回答中的顺序处理，包括离屏段落。

## 验证和证据边界

实际检查记录放在 `Evidence/`，应用生成的最新记录位于 `~/Library/Application Support/org.weibei.CatalystChatLab/Results/latest.json`。该目录不含生产资料。

应用内检查直接保护前插阅读位置、改宽、流式旧块复用和尾字、停止完成与读历史、跨段选区复用、卡片状态、数学和图片资源。CI 运行同一入口，不建额外测试矩阵。

“采样连续滚动与热回看”记录 12 秒前进、返回时的实际显示回调间隔及解析、测量、视图重建次数。**显示回调不是 GPU 呈现时间，不能换算或宣传为 FPS。** 首次准备、改宽和回看分别记录；同进程再切换样本不等于冷启动。不同机器、宽度、缓存状态和不同版本的结果不可直接拼成结论。

当前保留的首轮数据 `Evidence/before-layout-reuse.json` 来自优化前的真实 Catalyst Release 进程：6 项检查通过，但长历史改宽为 2101 / 3213 毫秒。这是需要修复的问题证据，不能当作最终候选性能。修复后的结果、桌面操作和采用判断见后续实际验证记录。

## 尚需单独验收的范围

本实验成功不等于正式魏碑已迁移。真实模型、生产资料库、笔记文件写闸门、PDF 阅读器、完整 GenUI、文件权限、多窗口恢复、插件以及正式签名和公证没有在本 PR 迁移。

完整候选与主线、#449、#451 的同机同内容端到端比较尚未完成；不据框架名称宣布 UIKit 获胜。鼠标拖选、中文组合输入、右键、焦点和附件滚动必须在真实 Mac 上验收，CI 通过不能替代手感。
