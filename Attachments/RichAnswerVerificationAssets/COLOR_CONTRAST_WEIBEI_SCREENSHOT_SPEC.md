# 魏碑颜色对比题截图与采样规范

颜色对比题不得从商业产品截图或网页截图抄取素材，必须使用魏碑自身可复现界面截图。

## 截图要求

- 使用真实魏碑窗口，记录分支、提交、构建命令、运行参数、macOS 外观模式、窗口尺寸、显示缩放。
- 截图对象必须是魏碑富回答或 Agent 回答区域中真实渲染出来的颜色块、文字、边框和背景。
- 截图保留原始 PNG，不做压缩、滤镜、放大、缩小、裁切后再采样。
- 若需要展示局部，可以另存派生裁切图，但采样数据必须来自原始截图。

## 采样规则

- 每组颜色至少取 3 个采样点：文字主体、背景主体、邻近边界。
- 每个采样点使用 11×11 像素窗口取中位数，避开抗锯齿边缘、阴影、半透明叠层和压缩噪声。
- 所有 RGB 值先转换为 sRGB 线性亮度，再按 WCAG 相对亮度公式计算对比度。
- 对比结果必须记录：采样坐标、窗口大小、RGB 中位数、相对亮度、对比度、截图 SHA-256。

## 留档格式

- 原始截图：`evidence/color-contrast/<case-id>/weibei-window-original.png`
- 采样表：`evidence/color-contrast/<case-id>/samples.csv`
- 计算说明：`evidence/color-contrast/<case-id>/contrast-report.md`

## 验收标准

- 不能只写“看起来清楚”；必须给可复算数值。
- 不能把设计稿颜色当成最终渲染颜色；只认真实窗口截图像素。
- 如果颜色不达标，记录失败，不用外部图片替换魏碑截图。
