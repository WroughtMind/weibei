# Logo

## 结构

图形由三部分组成：三根向下落地的墨柱、两个切入的负形、右下方一枚朱砂方块。它首先是一个厚重的 W，也像并排展开的书页、碑面和三列材料。

图形必须保持：

- 三柱等高，柱间负形宽度一致；
- 左上与右上各一个切角，中柱保持直角；
- 下方三个落脚稳定，两个连接谷口不粘连；
- 朱砂方块位于右下，不进入主体，不漂成句号；
- 朱砂底边与主体最低视觉线基本齐平，间隔固定。

## 为什么红点放在这里

它表达“落点”和“出处锚点”：内容读到哪里、论断落在何处。它在主体之后、靠近基线，因此更像一枚完成引用后的印记，而不是左上角的通知或右上角的状态灯。

产品界面中沿用同一认知：朱砂只标当前原文位置或当前出处。普通选择用石青，错误用系统语义红。

## 版本

| 版本 | 使用场景 |
|---|---|
| 拓印纹理 | README hero、宣传页、海报、≥256 px 品牌展示 |
| 透明平面 | UI 品牌位、网页、普通导出 |
| 单色黑 / 白 | 印刷、雕刻、单色限制、无障碍验证 |
| 反白 | 墨石主题和深色品牌背景 |
| 小尺寸光学版 | 16–64 px 图标、favicon、列表缩略图 |

## 文字组合

- 英文名称 `WEIBEI` 必须使用项目字体 `WeiBeiStele-Regular`；
- 英文副标、来源编号和品牌化技术标签使用 `WeiBeiSteleMono-Regular`；
- 不使用 SF Pro、Helvetica、Times 或其他“差不多”的字体替代英文品牌字；
- 两套项目字体不包含汉字，因此中文“魏碑”和中文副标使用系统 CJK serif / sans，不强行调用缺字字体；
- 可直接使用的导出位于 `assets/logo/exports/wordmark/`，字体预览位于 `assets/fonts/previews/`。

## 留白

以朱砂方块边长 `x` 为单位，图形四周至少留 `1x`。与产品名组成锁定组合时，图形与文字间距至少 `2x`。

## 最小尺寸

- 拓印纹理：最小 128 px，推荐 256 px 以上；
- 透明平面：最小 32 px；
- 16–31 px：只用小尺寸光学版；
- 低于 16 px 不展示完整标志，可只使用纯色 W。

## 禁止

- 不拉伸、旋转或改变三柱比例；
- 不移动、变圆、发光或动画化朱砂方块；
- 不加入渐变、科技蓝紫光、3D 挤压和额外投影；
- 不把 W 当“提问”“阅读”“笔记”等功能按钮；功能图标继续用 SF Symbols；
- 不在每张图上重新生成一个纹理不同、轮廓也不同的版本；
- 不让纸纹穿过实时正文，品牌纹理只留在品牌表面。
