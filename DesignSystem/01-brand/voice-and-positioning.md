# 对外表达

## 不从技术名词开场

不要用“本地优先 RAG + Agent + 课程记忆”当首页第一句话。先说用户能完成什么，再解释证据、本地和模型。

推荐首页顺序：

1. `把资料摊开，边读边记。`
2. `有问题就问，答案直接回到出处。`
3. `HTML、PDF、Markdown 和纯文本，在同一个 macOS 工作台。`
4. 再展示课程索引、本地数据、引用跳转和学习记忆。

## 中文短句

- 主标题：`读、记、问，在同一张纸上。`
- 功能描述：`打开资料，围绕原文提问，把可靠内容写进笔记。`
- 证据描述：`每条重要回答，都能回到文件、页码或章节。`
- 本地描述：`资料、索引和学习记录默认留在你的 Mac。`

## 英文短句

- Product line: `Read, note, ask — and return to the source.`
- Descriptor: `A source-grounded reading and notes workspace for macOS.`
- Evidence: `Open every important claim in its original file, page, or section.`

## 发布内容

宣传视频不要拍“输入一句话，AI 炫技”。拍一个完整的 30–45 秒任务：打开课程资料 → 选中一段 → 提问 → 点击引用回到原文 → 把确认后的结论写入笔记。一个视频只讲一个工作流。

## 不要写

- “AI 正在深入理解你的知识宇宙”
- “智能赋能沉浸式学习体验”
- “一站式、全链路、颠覆性”
- 没有证据的“绝不幻觉”
- 大量感叹号、emoji、拟人化邀功

像可靠桌面工具那样说话：短、具体、可核对。
