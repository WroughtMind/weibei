# 空间与网格

## 基线

采用 4 pt 基线，允许的常用值：

```text
2, 4, 8, 12, 16, 20, 24, 32, 40, 48, 64
```

2 pt 只用于光学微调和 hairline 附近；组件内距优先 8、12、16；页面与栏间距优先 20、24、32。

## 仓库现有布局约束

`ContentView.swift` 使用原生 `NSSplitView` 桥接，并通过 `PersistentPaneHost` 保持阅读和编辑状态。关键值：

- 课程目录宽度：最小 `220`，最大 `430`；
- 主要内容栏可读宽度：约 `560–780`；
- 分隔条命中宽度：`10`，其中只绘制安静的 `1 px` 线；
- 内容轨道休眠宽度：`28`；
- 可读阈值：`240`；
- 默认展开宽度：`420`。

这些值属于现有交互行为。修改时先验证拖动、重排和恢复，不要只看静态截图。

## 布局原则

- 主工作面连续铺开，不做三个独立浮动卡片；
- 栏之间用 1 px 纸面分界和排版层级，不靠大阴影；
- Agent 默认不应长期比阅读或笔记更宽；
- 窗口变窄时优先进入两栏或沉浸模式，不把三个栏硬压到不可读；
- 用户书写时不应因窗口轻微变化突然换栏或丢焦点；
- 用户可以重排 `reader / agent / notes`，设计不能假设它们永远固定左中右。

## 阅读宽度

统一阅读模式以稳定行宽为先。HTML 和 PDF 保持原始页面结构时，可让内容宽度由原文件决定；旁边的对话与笔记不得挤压到阅读正文低于可读阈值。
