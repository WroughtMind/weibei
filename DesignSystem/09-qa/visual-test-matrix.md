## App Icon

| 像素 | 检查 |
|---:|---|
| 16 | 三柱仍可数、负形不闭合、朱砂不脏 |
| 32 | W 清楚、红点可见、外框无锯齿 |
| 64 | 小尺寸平面版不过硬、纸色稳定 |
| 128 | 纹理开始可读，不像压缩噪声 |
| 256 | 轮廓与批准参考一致 |
| 512 | 纸纹、墨纹、朱砂边缘自然 |
| 1024 | 无透明光晕、无裁切、光学留白均衡 |

## 防止“AI 壳”回归

- [ ] 没有把每个区域包成大圆角卡片
- [ ] 没有紫蓝渐变、发光和大面积玻璃
- [ ] 没有 AI 星芒图标
- [ ] 没有无意义胶囊标签
- [ ] 没有正文下方的强纸纹
- [ ] 没有把 Agent 永久做成最大区域
- [ ] 没有无意义朱砂红点
- [ ] 引用确实能回到原文，不是装饰性编号
- [ ] 空状态只有一句说明和一个主要动作
