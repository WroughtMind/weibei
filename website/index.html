READ · ASK · NOTE

从原文开始，也回到原文。

魏碑不把阅读变成聊天的附件。提问发生在材料旁边，写下的内容仍由你决定。

  1. 01READ

    材料始终在眼前

    打开单个文件，或导入整门课程。PDF 页码、HTML 章节与当前选区都能成为可核对的上下文。

  2. 02ASK

    围绕正在读的句子发问

    问题线程与选区保持连接。之后再点回那道标记，仍能接着当时的问题继续读。

  3. 03NOTE

    确认之后再落笔

    Agent 可以提出笔记修改和学习状态更新；比较、保留或写入，最后一步始终交给学习者。

RETURN TO SOURCE

都有回原文的路。

  • 页准确的 PDF 页面
  • 节对应的 HTML 章节
  • 记与材料相连的笔记
