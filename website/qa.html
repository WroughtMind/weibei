常见问题

关于阅读、模型、隐私、安装和当前版本，这里尽量说得具体一点。

魏碑是做什么的？

魏碑是一个用来读资料、问问题和记笔记的 Mac 应用。文稿、围绕文稿的对话和笔记可以放在同一个窗口里。它比较适合需要认真读一段内容、针对原文追问，并且以后还想找回出处的时候。

可以读哪些资料？

目前支持 PDF、HTML、Markdown 和纯文本。扫描版 PDF 可以在本机识别文字，但速度会慢一些，识别结果也可能有错。遇到特别大的文件，魏碑可能只完成部分索引，这种情况会直接标出来，不会把不完整的搜索结果说成完整。

一定要接入 AI 才能用吗？

不用。导入资料、阅读、全文搜索和写笔记都不需要模型。只有提问、总结一段内容，或者请模型根据对话整理笔记时，才需要接入模型。

可以使用哪些模型？

模型由你自己选择。魏碑可以连接常见的在线模型服务、兼容 OpenAI 接口的服务，也可以使用本机的 llama.cpp 模型。在线服务可能需要 API Key 或相应订阅，费用由服务商收取。魏碑本身不要求注册一个新的魏碑账号。

我的资料会被上传吗？

课程、笔记和搜索索引保存在你的 Mac 上。向在线模型提问时，回答这个问题所需的文字会发送给你选择的服务商；如果使用本地模型，这一步也可以留在本机。魏碑无法替第三方模型服务承诺隐私政策，接入前仍然需要看一眼所选服务商的规则。

AI 会自己修改我的笔记吗？

不会。模型可以整理一份建议，但是否写进笔记由你确认。没有接入模型时，正常阅读和手写笔记也不受影响。

回答能回到原文吗？

围绕已导入资料提问时，魏碑会尽量在回答里附上引用，点击后回到对应页码或小节。模型仍然可能理解错，重要结论最好回到引用的原文再确认一次。

现在支持哪些电脑？

当前版本需要 macOS 14 或更高版本，现有构建面向 Apple 芯片 Mac。Intel Mac 和 Windows 版本会继续评估，但现在还没有确定的发布日期。只有真实安装包发布后，官网才会把对应版本标成可以下载。

在 Mac 上怎么安装？

下载 DMG 后双击打开，把魏碑拖进“应用程序”即可。当前社区构建首次打开时，可能需要到“系统设置”的“隐私与安全性”里确认一次。无需也不建议关闭整个系统的安全检查。

现在适合长期使用吗？

魏碑仍在持续开发。阅读、搜索、对话和笔记这些主要流程已经可以使用，但仍然可能遇到错误，也会继续调整。重要资料和笔记请像平时一样做好备份，碰到不对的地方可以从反馈页告诉我们。

魏碑是开源的吗？

应用代码在 GitHub 上公开，使用 MIT 许可证。魏碑的名称、标志、截图和其他品牌素材不包含在这个许可证里。如果准备修改或重新分发应用，请先阅读仓库里的许可说明。

遇到问题或有建议，发到哪里？

可以使用官网的“反馈”页面。填好后，页面会带着标题和内容前往对应的 GitHub 表单，你可以在提交前再检查一遍，不会自动替你发布。
