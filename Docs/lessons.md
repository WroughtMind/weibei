# Lessons

## 2026-08-22 学习记忆空 ID 假成功

- 现象:模型调用了写入工具,回答声称已写入,标签和 workspace 都是空的。
- 根因:写工具把 `memoryID`/`entryID` 做成可选字符串,模型新建时传 `""`;共用解码器把空字符串当"有 ID",Store 解析 UUID 失败后整包丢掉;工具却在 Store 落库前就报成功,模型在循环里拿不到真回执。读回执字段是 `id`,写参数是 `memoryID`,模型不知道该抄什么,只能自己填。
- 规则:可选记录 ID 的空字符串=没传=新建,由系统分配。ID 只从读回执/写成功回执抄写,禁止模型编 UUID。有 Store 的 Native 写入必须在工具循环里落库,成功回执带上系统分配的 ID,失败当作工具错误回喂本轮。不要只在回复结束后静默 apply。
- 不要改 `StudyAgentProposalDecoding` 去猜乱字段;空 ID 在 Native execute 入口剥掉,Store 再兜一层。

## 2026-08-22 多选题"没选=永久砍"把用户要的功能砍掉了(选区胶囊计划)

- 现象:重做"问|记"胶囊计划时,用多选题问旧功能去留,用户没勾"原文标记",我把它写成"永久砍";用户纠正:这个现在就要做。
- 根因:把**未选择**当成了**明确否决**。用户当时只是排序注意力,没勾≠不要。
- 规则:砍功能必须来自用户原话;多选题未选项最多记"未排期",要砍就单独确认一句。同理,推断了用户上次"哪里效果差"而没核实的地方,都要在方案里标"推断,待你纠正"。
