# Lessons

## 2026-08-22 学习记忆空 ID 假成功

- 现象:模型调用了写入工具,回答声称已写入,标签和 workspace 都是空的。
- 根因:写工具把 `memoryID`/`entryID` 做成可选字符串,模型新建时传 `""`;共用解码器把空字符串当"有 ID",Store 解析 UUID 失败后整包丢掉;工具却在 Store 落库前就报成功,模型在循环里拿不到真回执。读回执字段是 `id`,写参数是 `memoryID`,模型不知道该抄什么,只能自己填。
- 规则:可选记录 ID 的空字符串=没传=新建,由系统分配。ID 只从读回执/写成功回执抄写,禁止模型编 UUID。有 Store 的 Native 写入必须在工具循环里落库,成功回执带上系统分配的 ID,失败当作工具错误回喂本轮。不要只在回复结束后静默 apply。
- 不要改 `StudyAgentProposalDecoding` 去猜乱字段;空 ID 在 Native execute 入口剥掉,Store 再兜一层。

## 2026-08-22 多选题"没选=永久砍"把用户要的功能砍掉了(选区胶囊计划)

- 现象:重做"问|记"胶囊计划时,用多选题问旧功能去留,用户没勾"原文标记",我把它写成"永久砍";用户纠正:这个现在就要做。
- 根因:把**未选择**当成了**明确否决**。用户当时只是排序注意力,没勾≠不要。

## 2026-08-25 流式回答结束时的"闪一下+内容上移"根治(前缀稳定性)

- 现象:Agent 流式回答结束后 UI 闪一下、内容上移;含引用/数学/货币时更明显。
- 根因:三层文本变换在流式中间态**回改已显示字符**,打破"下一帧必须以前一帧为前缀"的不变量,触发 WebView 全量重解析 + fade 装饰重启(闪):
  1. `AgentCitationParser.parse` 在 `[材料:…]` 标记闭合那一刻把整段标记从文本里剥掉(长度回缩);
  2. `AgentChatKaTeXMarkdown.prepare`(原生)把 `\hat \b`→`\hat{\b}`、`\[`→`$$` 等,部分形式与完整形式的转换结果互不为前缀;
  3. `normalizeMarkdownSource`(JS)的货币保护/定界符转换有同样问题。
- 规则:**凡是"流式增量推送 + 文本变换"的管道,变换只能作用于"已决"文本**。在每一层入口用 `withholdUndecidableStreamingTail` 截断"下一字符会改变解释"的尾部(未闭合定界符、`\hat` 参数链、行首 `[`、尾部裸 `\`/`$`/`<`),放行后一次性转换到位;finalize 时不截断。变换函数本身保持纯粹,流式上下文由调用点传入。
- 验证方法:harness(`WEIBEI_STREAM_PROBE=1 WEIBEI_STREAM_PROBE_SCENARIO=<name>`)跑 plain/long/sources/currency/inlinemath/math/mathline 七场景,`prefix-break` 与 `prefixMatch = 0` 必须全为 0。探针默认关闭,勿删 harness,回归时直接复用。
- 教训:修流式渲染先证"前缀单调"不变量,再谈动画/高度;在错误层(web)修原生引入的断裂会反复打地鼠。环境变量名以源码为准,不要凭记忆。
