# 工程教训（lessons）

- 2026-08-16（源自《项目体检行动方案》阶段 1 第 7 条）：**worktree 与任何用户数据一律禁止放在 /tmp**。macOS 重启会清空 /tmp，本次用户的真实课程库曾因放在 /tmp 差点随重启丢失。代码分支现场用 `~/projects/` 下的持久目录；用户数据只放 `~/Documents/` 下 App 指定的持久位置。
- 2026-08-18（收尾清扫）：临时验证产物（冒烟工作区、截图、日志）可以放 /tmp，但**长期现场（worktree、未推送分支、未归档补丁）不得留在 /tmp**；每天收尾时把仍在推进的现场迁回持久目录或直接入库，其余用 `git worktree remove` 清掉。
