# 魏碑旧富回答开放场景参考（历史）

状态：仅保留为旧实现的观察样本，不是当前生成规则或验收题库

这里曾记录 T1/T2、旧富回答协议和固定场景的交互参考。当前唯一生成式界面方法已经改为 `visualize`：文字足够就用 Markdown，静态关系用 Mermaid，只有动态变化、空间运动或可调输入确有价值且宿主成熟时才生成动态片段。

旧场景可以帮助回看真实窗口问题，但不得：

- 作为组件清单、family/renderer 目录或第二套质量规则；
- 要求当前来源或素材列表先许可生成；
- 诱导模型恢复旧工具、旧 Schema 或旧网页运行时；
- 用固定题命中代替真实用户理解和操作验收。

当前决策见[《魏碑沿 Visualize 技术路线自建生成式界面》](生成式界面基础与Visualize借鉴.md)。旧正文仍可从 Git 历史取证。
