# 选区与主会话联动

日期：2026-09-14。实施分支：`codex/selection-chat-context`，基于 `bd4e02f5`。

## 确定的交互

| 操作 | 结果 |
| --- | --- |
| 主会话可见时选中文字 | 输入框上方自动出现选区标签，复用现有悬停预览，不发送问题。 |
| 改选另一段 | 自动标签更新；用户另外添加的附件保留。 |
| 点击主标签的关闭 | 后续主问题不再携带该选区，同一选区事件不立即把标签加回来。 |
| 点击原文旁的“问” | 展开浮窗，主标签、草稿和当前会话保留。 |
| 浮窗发送、重试、回填或停止 | 操作所属问答，不改主会话内容。关闭和回访保留问答及未发送草稿。 |
| 主会话首次创建浮窗 | 继承此刻主会话最后一个完整轮次，之后各自继续。主会话不可见时从原文开始。 |
| 主会话问“比较刚才两段解释” | 助手查找并读取实际问答，再综合回答并附讨论引用。 |
| 点击讨论引用 | 打开对应浮窗并定位具体消息，主会话保持原位。 |
| 在主会话或浮窗内引用文字 | 引用写入所属输入框，光标跟随到该输入框。 |

主会话发送时只使用可见附件。点击“问”没有在主输入框发送问题，因此不消耗主标签。新的正文选区仍沿用原有紧凑操作条；已经固定的浮窗保持原问答。

## 实现取舍

复用现有按会话保存的消息文件、运行实例、停止和流式显示。选区问答编号同时是独立会话编号，新增所属主会话关系，不再从主消息数组筛选浮窗内容。输入控件按目标会话读写草稿，键盘发送只作用于获得焦点的输入框。

历史在浮窗创建时复制一次，包含已完成的工具轮次和压缩记录，不复制正在生成的尾部。旧问答从其实际消息编号创建独立记录，同时补齐所属会话，保证重试和回填仍在浮窗；原主会话记录保留。读取不完整时停止并显示错误，不保存为空记录。

“查找问答”和“读取问答”接入现有工具链。默认关联当前主会话和资料，跨会话查询由问题需要决定；按已有用户消息时间排序。读取结果保留追问、修正、回答状态及消息引用。讨论记录与原始资料分开，核实内容时继续读取原文。

不增加“带回主会话”按钮、手动多选问答、常驻历史卡片、每次请求附带的问答清单，或任意“最近几条”限制。复用现有来源预览与引用界面，没有新依赖。讨论引用属于本机聊天数据，课程便携资料不携带这些本机引用。
