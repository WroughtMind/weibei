# 统一拖放导入定案

日期：2026-09-29。状态：已按用户确认方案实施，等待组合构建与真实拖放验收。

## 用户流程

首页、普通工作台、课程内和从 Dock 打开文件都进入同一确认面板。文件选择器入口也复用该面板。普通入口默认“通用资料”，课程入口默认当前课程；明确的笔记入口只接受 Markdown，并默认导入为笔记。

课程创建页里预先选择的初始文件也只在课程创建完成后进入同一确认面板，不会直接复制。若当前批次正在导入时又从 Dock 打开文件，新文件会显示为下一批待处理项；用户可以在当前结果页继续核对，不会静默丢掉选择。

面板先列出实际可导入文件、不支持项、重复项和同名冲突，再选择归属。通用资料始终在首项，课程支持搜索和新建。新建课程沿用原有资料库目录与权限流程；取消新建只关闭新建面板，原批次和当前选择保留。

确认文案直接写目标，例如“加入《投资学》”。确认前只读取文件信息和比对内容，不创建目录、不复制文件。确认后仍在同一面板显示当前文件和进度，可停止剩余文件；已经完成的文件保留。

## 数据处理

| 情况 | 处理 |
| --- | --- |
| 支持的普通文件 | 调用现有通用资料复制或课程文件事务 |
| 内容完全相同且同名 | 标为“重复，跳过”，不再次复制 |
| 同名但内容不同 | 确认前显示新名称，确认后保留两份，不覆盖 |
| 不支持的文件 | 确认前列出并跳过；全部不支持时禁用确认 |
| 文件夹内不支持的文件 | 沿用既有安全遍历范围递归列出；隐藏项、应用包、符号链接和 `node_modules` 不越界展开 |
| 同批同名且内容相同 | 第二份标为重复并跳过，只登记一次成功 |
| 单个文件失败 | 保留本批已成功结果，显示失败原因 |
| 重试 | 只重新核对和导入失败文件 |
| 停止 | 当前正在处理的文件结束后停止剩余文件 |

重复与冲突判断直接复用底层复制能力的同一份逐字节比较和命名规则，没有增加“内容去重”声明或另一套摘要数据库。课程写入继续使用现有可恢复事务；通用资料继续写入现有资料库目录。原文件始终保留。

## 完成后的去向

单个成功文件可直接打开。多个成功文件可进入对应的通用资料列表或课程文稿/笔记页，本批文件以朱砂浅底短暂突出三秒。结果面板分别显示成功、跳过和失败数量；停止状态另行说明未继续处理剩余文件。

## 验收边界

自动行为检查覆盖：确认前取消零写入、停止剩余任务、部分失败保留成功、只重试失败项、碰撞预检与真实复制使用同一规则。组合构建与测试由主任务统一执行，建议过滤器：

```sh
swift test --filter ConfirmedFileImportTests
swift test --filter HTMLResourceImportTests
swift test --filter LibraryRelativeOnlyTests
```

真实 App 仍需在最终候选包验证：首页、工作台、课程文稿、课程笔记及 Dock 五个入口；Finder 多文件与文件夹拖入；新建课程取消/成功；停止按钮；部分失败重试；单个打开与批量定位高亮。静态代码和自动检查不能替代这些拖放体验证据。
