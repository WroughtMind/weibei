# 磨砂玻璃调整

本轮先改善磨砂玻璃，沿用已有「雾璃 · 玄璃」主题与浓度滑杆。

- 浅色按已选示意 A → C：低浓度保留细雾，高浓度增加遮蔽，底色改为中性雾白。
- 深色按已选示意 D：烟灰底色与暖白文字，随浓度调整遮蔽。
- 透亮玻璃继续使用现有表现；不增加主题、滑杆或材质框架。
- 浓度只作用于背景材质和遮罩，正文及图标不随之变淡。
- 原生界面与编辑器的浮动工具栏、文字及代码底色同步调整。

使用现有编译、外观主题与偏好检查，并校验编辑器资源构建。
