# 磨砂玻璃调整

本轮以用户提供的 macOS 日历截图为效果参考：背景文字失去可辨识字形，仍保留模糊的颜色与光斑，前景文字清晰。

- 沿用「雾璃 · 玄璃」和现有浓度滑杆，不增加主题或设置项。
- 磨砂使用完整不透明度的系统浮层材质采样背景，不把清晰背景混回模糊结果。
- 移除磨砂的整窗前景遮罩、空白首页的纸面渐变，背景仅保留轻微调色。
- 浅色用系统弹出面板材质，深色用系统 HUD 材质；透亮玻璃行为不变。
- 现有浓度滑杆连续调整透色，没有低端无效区间；约 40% 保留已获用户认可的轻染效果，高端增强遮蔽但保持系统模糊层完整。系统材质的模糊半径由 macOS 管理，本次不声称实现连续可调的模糊半径。
- 不引入网页折射库、桌面截图模拟背景或私有模糊接口。

## 验证

编译和已有外观检查验证主题切换与浓度保存；真实预览版另行观察背景细节柔化与透色。
自动检查不能代替用户对材质效果的确认，PR 在效果确认前保持草稿。

## 主题命名

App 与 Pages 统一使用画作名：吊桥、大桥骤雨、圣拉扎尔车站、蓝与银的夜曲。
每组深浅共用名称，不附加材质说明；内部主题标识和用户选择保持不变。
