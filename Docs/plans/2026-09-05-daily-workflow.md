# 日常工作流改进实施计划

用户已授权按已定方案实现、创建 PR，并准备候选 App 验收；本任务不包含正式发布。所有改动集中在一个分支、一个工作目录、一个 PR。

## 交付范围

1. 快捷入口搜索全部资料、笔记和聊天，包含通用内容；结果提供类型、标题、归属、命中片段并直接打开，复用已有索引和命令入口。
2. 新建笔记直接创建并聚焦正文，自动保存，之后命名。课程入口归当前指定课程，通用入口归通用笔记；进入 NOTE 不自动新建。
3. 不同对话分别运行、显示和停止，不设人为并发数量上限；请求输出、取消、工具写入保持所属对话，沿用文件写闸门防覆盖。
4. READ／NOTE 共享课程文件选择器：文件全部展开，淡课程底色、轻圆角、文本与线性图标；课程标题旁常驻加号；去掉课程钻入和重复标题。按窗格宽度自动分列，独立列向下堆叠，短块不拉高。全屏容器水平居中、有最大宽度；正常纵向滚动。集合末尾并排文字入口用于新建课程、导入；全局入口不绑定末尾课程。8／9项直接显示，不截断成查看全部。
5. 保留空白启动，有历史时提供小型“继续上次”按钮，点击恢复保存的资料、笔记、对话、布局与可用位置；不重新发送草稿、不重启请求。
6. 保留一次性的存储确认，AI 配置提示后置到首次使用 AI，保留已经输入的请求。
7. 修正延迟滚动使用旧追随状态的问题；不改聊天渲染路线。

## 视觉基准

最终基准来自用户选定的 NOTE 图片：课程块按内容高度，整组居中，集合末尾直接显示“＋ 新建课程”“导入笔记…”。宽度分列及三栏图片只补充场景：不采用其中的大标题、顶部新建按钮或被拉长的短块。READ 相同，尾部为新建课程和导入资料。

开发时以当前课程顺序为稳定排序，列数依据窗格宽度变化；不新增排序配置、拖动看板或额外管理首页。具体尺寸以候选 App 调整。

先完整编译，随后只运行直接保护搜索覆盖、新建归属、恢复不重放、并发不串会话／取消和写入隔离的行为检查，复用项目现有检查。布局用实际内容和代表性窗格宽度验证，不写像素快照或源码措辞测试。必要时补最少的用户行为回归，不新增测试框架、通用配置或兼容层。

本地通过后推送完整 CI，修复真实失败；准备候选 App 并轻量验收，最终打开给用户。真实界面检查用画中画，不干扰正常桌面。用户已授权打开做好的版本，但没有另行授权正式发布或合并。
