# 已定案的决策（用户逐项确认）

1. **朱砂主按钮文字色**：`Color.white` → `WeiBeiTheme.onCinnabar`，与其他红底控件统一。
2. **笔记改名后的书签空壳死代码**：直接删除；文件被外部移动后仍可找回的能力将来需要时再正式立项。
3. **动效文档**：`DesignSystem/05-motion/motion.md` 的 token 表对齐 `WeiBeiMotion` 源码现状，此后动效改版必须同步更新该表。
4. **新旧异步写法混用**：经全仓核实，视图层 80+ 处 GCD 调度是 AppKit 桥接与动画节拍的标准用法，不构成混用问题；Stores 仅剩 1 处且带注释说明节拍意图。**结论：不清洗，此项关闭。**
5. **workspace.json 坏档**：三代滚动备份 + 启动打不开时坏档改名留存 + 自动尝试最近备份 + 全部失败时明确横幅提示（不再无声空白）。
6. **保存失败全局可见**：挂到全 App 级错误横幅通道，带重试按钮。
7. **交互等待上限**：交互路径等待 60 秒超时，弹横幅可重试；大文件导入的后台进度路径不受影响。
8. **空启动页 IMPORT 入口**：点击后先引导新建课程库——提供默认路径、允许自选位置；空态文案不提"拖资料到这里"（彼时还没有课程空间）。
9. **文稿 / 笔记空列表**：给"新建课程"入口；课程空间内资料为空也给导入 / 新建入口。
10. **窗口最小宽度**：降到约 780，三档自适应（≥1120 完整布局 / 780–1120 双栏收窄 / 沉浸式更窄最小宽），做完给用户看效果。
11. **主题跟随系统**：八主题两两配对（纸面↔砚黑、宣纸↔碑石、玻璃亮↔玻璃暗、薄雾↔石板），外观三选项：跟随系统 / 亮色 / 暗色。
12. **玻璃浓度**：玻璃主题下提供 0–100 无级滑杆；**不做**系统"降低透明度"联动。
13. **圆角新语言**：方向已反转（不走方正），先出规范草案给用户挑，定稿后全仓收敛越界圆角（约 29 处 9–14pt + 13 处 5pt 野值 + 输入框组件 7pt 基准）。
14. **编辑器桥命令吞吐**：就绪前排小队列保序、就绪后按序补发（同类正文更新合并只发最新）；执行错误记日志不再吞掉。
