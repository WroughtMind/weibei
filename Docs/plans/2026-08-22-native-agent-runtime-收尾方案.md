## 4. 用户复核后追加（2026-08-22，第二轮回）

### W5 主动检索级联（推翻 Q16「追问」行为）

用户裁决：Q16 的「反问你查哪种利率」就是失败。魏碑的 agent 必须主动，不许用反问打断心流。目标行为是级联检索：

1. 用户已打开/选中的文稿、笔记上下文里有答案 → 直接用；
2. 没有 → 搜课程库（`weibei_course_search` → `weibei_course_read`）；
3. 课程没有 → 工作区相关文件范围查一圈；
4. 都没有 → 网页搜索兜底，并在回答里说明来源（「课程里没有，我上网查了」）。

只做行为引导（工具描述 + 系统提示的检索策略段），不做硬约束、不禁止网页搜索。若工作区级文件检索目前没有对应工具，本轮先做课程层，把笔记库检索工具列为后续能力并在报告里注明。

验收（luna low 定点重跑，防过校正）：

- **16**（课程里确有《利率课程》）：预期 `course_search → course_read`，答案来自课程，不反问；
- **05**（课程里没有「准备金」）：预期先搜课程，如实报无匹配，再决定上网或如实收尾；
- **37**（与金融无关的冷知识）：预期不触发课程检索或快速落空后正常作答，不许每题都先搜课程。

### W6 真实 App 后端切换开关（临时设施）

用户裁决：验收必须验 native，不能拿默认的 Pi 冒烟。做一个持久化的后端切换开关（调试用途），用户无需环境变量即可在真实 App 里切到 native；默认后端仍不动。若落点涉及共享核心面（WorkspaceStore / WeiBeiApp / ContentView / StableDocumentWorkspace 等），先在 MR #285 里声明占用。

**生命周期（用户明确）：此开关是临时设施，只为本次验收存在。** 冒烟通过、默认后端切为 native、删除 Pi 之后，开关随删除 Pi 的提交一并移除，正式产品里不留后端切换入口。

验收：用户在真实 App 里切到 native 后，按 `Docs/audit/2026-08-22-native-runtime-用户验收清单草稿.md` 四条逐项确认；清单开头补一行切换步骤。

### 关于「直接删 Pi」

用户提出过直接删 Pi。工程判断：**冒烟前不删**。删了就没有对照组和回退路径，冒烟一旦暴露 native-only 问题会被动。正确顺序：W6 开关验 native → 冒烟四条通过 → 单独一个提交把默认后端切为 native → 用户单独授权后删除 Pi/Bun（届时才出不含 Pi 的公证包）。删 Pi 的动作本身不改任何 agent 代码，只是从打包清单移除运行时载荷并收尾引用。
