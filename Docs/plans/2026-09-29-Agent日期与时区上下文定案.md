# Agent 日期与时区上下文定案

## 结论

学习助手在每次发送前读取系统当天日期和本地时区。新会话写入一条会话环境状态；同日且时区未变时复用，跨天或时区改变时才追加新状态。

## 边界

- 环境状态只进入模型上下文和本地会话账本，不显示为聊天气泡，也不增加用户设置。
- 固定系统提示词保持不变；环境状态作为独立消息发送，不写入滚动摘要。压缩后从账本重新附带最新状态。
- 只提供日期、时区名称和当前 UTC 偏移，不提供每轮时间戳。精确时间仍由确有需要的功能单独读取。
- 这项改动只补齐时间环境输入，不代替事实核实，也不承诺消除其他事实错误。

## 验收

自动检查覆盖新会话、同日连续轮次、跨天、改变时区、账本恢复和上下文压缩。判断标准是固定提示词不变、每次请求仅有一条最新环境消息、无变化时账本不重复追加。
