## 阶段 0 — 课程库迁出 /tmp（纯手工数据操作，不改代码，最先做）

**目标**：用户数据（库根目录 + workspace.json）在重启前脱离易失位置，且全程可回退。

1. **让用户完全退出魏碑 App**（workspace.json 在 App 运行时持续写入，
   不退出则备份的是运行中快照）。用 `pgrep -fl -i weibei` 确认无进程再继续。
2. **前置门禁：目标必须不存在或为空**，否则停下报告，禁止静默混合：
   ```bash
   [ ! -e ~/Documents/魏碑课程库 ] || [ -z "$(ls -A ~/Documents/魏碑课程库)" ] || { echo 目标非空，停; exit 1; }
   mkdir -p ~/Documents/魏碑课程库
   ```
3. **备份（放课程库之外）**：
   ```bash
   B=~/Documents/魏碑迁移备份-20260816 && mkdir -p "$B"
   cp "$HOME/Library/Application Support/WeiBei/workspace.json" "$B/workspace.json.pre-migration"
   tar czf "$B/app-support-backups.tar.gz" -C "$HOME/Library/Application Support/WeiBei" Backups
   tar czf "$B/tmp-library-full.tar.gz" -C /tmp WeiBei-security-hardening-web
   tar tzf "$B/tmp-library-full.tar.gz" | wc -l   # 归档可读性校验：能列出且条目数>0
   ```
4. **迁移数据目录**（源码残骸不进课程库）：
   ```bash
   for d in 通用笔记 通用资料 Attachments Notes Config; do
     [ -e "/tmp/WeiBei-security-hardening-web/$d" ] && \
       rsync -a "/tmp/WeiBei-security-hardening-web/$d" ~/Documents/魏碑课程库/
   done
   ```
5. **单列迁移独立笔记**（v2 的遗漏项）：
   ```bash
   mkdir -p ~/Documents/魏碑课程库/Notes
   cp ~/Documents/魏碑/Notes/新概念笔记.md ~/Documents/魏碑课程库/Notes/
   ```
6. **全量校验（不是抽样）**：对每个已迁目录跑
   `diff -r /tmp/WeiBei-security-hardening-web/<d> ~/Documents/魏碑课程库/<d>`，
   全部无输出才通过；另 `diff` 独立笔记两份副本。
7. 用户打开 App，**在 App 内重新选择库根目录**为 `~/Documents/魏碑课程库`
   （必须走 App 入口刷新安全书签；禁止手改 workspace.json）。
8. **验收**：
   - `python3 -c "import json;print(json.load(open('$HOME/Library/Application Support/WeiBei/workspace.json'))['courseLibraryRootPath'])"`
     输出为新路径；
   - 打开旧笔记内容完整；新建一篇、修改一篇；重启 App 后仍在；
   - `新概念笔记.md` 在 App 中可见可开。
9. **源保留门禁**：用户验收通过前，/tmp 源目录与所有备份一律不删；
   验收通过后 /tmp 源也不主动删（重启自然消失），备份保留至少一周，由用户决定删除。

**回退路径**：若迁移后 App 异常——退出 App，恢复 `workspace.json.pre-migration`，
在 App 内重选回原目录（若 /tmp 仍在）或解包 `tmp-library-full.tar.gz` 到持久位置后重选。

## 阶段 2b — 存量缺失条目处置（代码 PR：`codex/missing-items-rebind`）

1. **显式化**：缺失条目在 UI 明确标记"源文件缺失"，不再静默表现为找不到。
