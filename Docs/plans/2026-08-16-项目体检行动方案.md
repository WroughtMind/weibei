## 阶段 0 — 课程库迁出 /tmp（纯手工操作，不改代码，最先做）

> ✅ 完成于 2026-08-16：课程库已脱离 /tmp，当前库根在持久磁盘 ~/Documents/魏碑资料库（App 内指向）；/tmp 原目录已随重启消失。

**目标**：用户笔记数据脱离易失目录。

1. 让用户完全退出魏碑 App。
2. 建目录：`mkdir -p ~/Documents/魏碑课程库`
3. 只拷数据目录，不拷源码残骸：
   ```bash
   for d in 通用笔记 通用资料 Attachments Notes Config; do
     [ -e "/tmp/WeiBei-security-hardening-web/$d" ] && \
       rsync -a "/tmp/WeiBei-security-hardening-web/$d" ~/Documents/魏碑课程库/
   done
   ```
4. 校验：两侧 `find ... -type f | wc -l` 数量一致；抽样 diff 几个文件内容一致。
5. 整体备份保险：
   ```bash
   tar czf ~/Documents/魏碑课程库/_migration-backup-20260816.tar.gz \
     -C /tmp WeiBei-security-hardening-web
   ```
6. 让用户打开 App，在 App 内重新选择库根目录为 `~/Documents/魏碑课程库`
   （必须走 App 入口，安全书签才有效；不得手改配置文件）。
7. 冒烟：打开旧笔记确认内容在；新建一篇、修改一篇；重启 App 确认持久。
8. 备份 tar 保留一周后由用户删除。/tmp 原目录不主动删（重启自然消失）。

**验收**：App 指向新目录且笔记完整；备份 tar 存在于持久磁盘。

   缺失的补齐。产出一张"失败分支 × 用户反馈"对照表放入 PR 描述。
