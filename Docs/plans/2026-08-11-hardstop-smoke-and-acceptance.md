## 人工验收场景清单（请你点一遍）

用上面候选 `魏碑.app`。**不必全绿才停**——标出「过 / 不过 / 未测」即可。重点是本批 hard stop；后半含 #176–#188 补漏。

### A. 本批 hard stop（必测）

1. **外部编辑可找回（C1）**  
   打开课程笔记 → 用外部编辑器改成内容 B 并保存 → 回到魏碑再编辑保存成 C → 在备份环（或应用支持目录笔记备份）里应能找到内容 B 的备份；磁盘最终为 C。

2. **连续自写不刷备份（C1）**  
   同一笔记连续保存多次、中间无外部改动 → 备份环不应每次都新增（允许首次无基线时多一份）。

3. **写回失败草稿活过重启（C2）**  
   尽量制造写回失败（只读目录 / 权限拒绝）→ 草稿仍在编辑器 → 退出再开 → 草稿仍在，且会重试写回。

4. **外部改动约 1 秒内刷新（C3/H5）**  
   打开笔记、无脏输入 → 外部原子保存（另存覆盖）→ 约 1s 内正文刷新。  
   再试外部就地追加（终端 `echo x >> note.md`）→ 也应刷新。

5. **自动保存后监听仍活（C3）**  
   在魏碑里改一点并等自动保存 → 再外部改文件 → 仍应刷新（不得第一次自写后监听永久死）。

6. **打字不被重载打断（H4）**  
   连续快速打字时，另窗口改同一文件 → 输入不得被静默重载冲掉；保存后外部版进备份环。

7. **分叉拷贝弹确认（H2）**  
   导出课程副本 → 本机再改进度 → 原根失联后用「纳入已有文件夹」指到副本 → 应**弹一次确认**（文案含「以本机进度为准」），**不得**无提示自动绑。

8. **无歧义重绑仍顺滑（H2 对照）**  
   本机未改、副本与本机 digest 一致、原根失联 → 可自动确认，不无故弹窗。

9. **根外 symlink 不进课程（H3）**  
   在课程「笔记」里放指向课程外的 `.md` symlink → 重扫/重开后不应登记为课程笔记；根内指向根内的 symlink 仍可用。

### B. 存储简化 / 性能批次补漏（#176–#188，建议测）

10. **永不拒绝保存**  
    外部已改过的笔记在魏碑再保存 → 应 last-writer-wins 成功，不出现「冲突拒绝」类阻断。

11. **横幅是缺陷信号**  
    正常路径不应常驻红/黄横幅；若出现，记下触发步骤。

12. **课程资料库换绑**  
    资料库路径仍可用时，换到别处应有合理行为（不得静默把课程绑错库）。

13. **废纸篓 / 移除课程**  
    从魏碑移除课程 vs 移到废纸篓 → 登记与文件边界符合预期，无幽灵课程。

14. **大笔记滚动与输入**  
    打开较长笔记打字、滚动 → 无明显卡顿；切笔记后内存/界面正常。

15. **Chat 基础**  
    打开课程 Chat 发一条 → 回复渲染正常；历史滚动不卡死。

16. **退出再开**  
    有未保存输入时退出再开 → 草稿/状态不丢（与场景 3 互补）。

17. **可携带导出**  
    导出课程副本到新文件夹 → 再纳入 → 内容与关系基本完整。
