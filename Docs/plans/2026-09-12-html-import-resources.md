# HTML 导入保留网页样式

用户只拖入一个 HTML，导入自动收集其引用的本地样式、图片、字体和脚本，包含样式表的递归依赖；导入后仍是一份可移动、可导出的 HTML。通用资料和课程资料采用同一处理。缺失资源不阻止保存正文，只在阅读区角落显示可展开的小状态；正常导入不新增确认或授权操作。默认保留网页原貌，阅读配色作为主动选择。

## 实现边界

- 复用系统 HTML 解析能力，将可读取的本地资源嵌入导入副本；不修改原文件、不执行网页脚本来收集资源、不下载网络资源。
- 保留现有文件事务和路径校验，网页无需获得资料库之外的读取权限。
- 缺失、不可读或超出已有资源读取预算的依赖记录为不完整，导入仍成功；不假装资源完整。
- 用合成网页覆盖相邻资源目录、嵌套样式、图片、字体、脚本、资源缺失和目录越界；验证两种入口以及移动后阅读。

## 实现和验证

系统 HTML 解析器收集文档中的本地引用，把依赖嵌入导入副本。课程事务分别校验原件和打包后的副本，保存失败时清理的是本次生成的副本，原件保留。读取只针对被引用的普通资源文件，拒绝符号链接和隐藏路径；保留资源完整性校验，不扩大网页的磁盘访问范围。

本地六项检查通过：新增四项覆盖两个真实导入入口、移走原目录后的样式/图片/字体/脚本、资源不可读及完整性校验失败、课程保存失败保护；另有现有课程文件安全及文件身份检查。四份实际课件在原始读取与仅加载导入副本之间的计算样式、截图像素和练习按钮结果一致，私人课件与截图不提交仓库。

支持静态声明的资源和字面量模块引用；不在导入时执行网页来发现动态拼接的请求，不归档网络资源，也不改写网页内容安全策略。依赖循环、超出读取预算或不可访问的资源记录为不完整。真实应用界面验收和远端检查另行记录在合并请求中。
