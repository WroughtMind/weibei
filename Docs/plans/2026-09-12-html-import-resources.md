# HTML 导入保留网页样式

用户只拖入一个 HTML，导入自动收集其引用的本地样式、图片、字体和脚本，包含样式表的递归依赖；导入后仍是一份可移动、可导出的 HTML。通用资料和课程资料采用同一处理。缺失资源不阻止保存正文，只在文稿标题处显示可展开的小状态；正常导入不新增确认或授权操作。默认保留网页原貌，阅读配色作为主动选择。

## 实现边界

- 复用系统 HTML 解析能力，将可读取的本地资源嵌入导入副本；不修改原文件、不执行网页脚本来收集资源、不下载网络资源。
- 保留现有文件事务和路径校验，网页无需获得资料库之外的读取权限。
- 缺失、不可读或超出已有资源读取预算的依赖记录为不完整，导入仍成功；不假装资源完整。
- 用合成网页覆盖相邻资源目录、嵌套样式、图片、字体、脚本、资源缺失和目录越界；验证两种入口以及移动后阅读。
