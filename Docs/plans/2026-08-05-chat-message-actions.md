# 对话消息操作

## 本次实现

- 用户气泡悬停时轻微抬起，点击整条气泡即复制且不显示操作图标；助手回答悬停时显示无底色复制图标，复制去掉界面引用标记并保留 Markdown 原文。
- 仅最后一条完整助手回答可重新生成；复用原问题的课程与选区上下文及现有发送链路，替换旧回答，不重复追加用户问题。
- 历史折叠按钮补充克制的胶囊底与悬停反馈，不改变长会话分页规则。

## 共享文件占用

- 占用：`Sources/WeiBei/Stores/WorkspaceStore.swift`、`Sources/WeiBeiSelfCheck/main.swift`
- 负责人任务：`codex/chat-message-actions`
- 释放条件：编译、自检、真实窗口验收完成，草稿合并请求更新且工作树干净。

## 验收

- 复制含公式的用户问题和助手回答，粘贴后仍是可编辑 Markdown。
- 重新生成后只有一条原用户问题，旧回答被新的流式回答替换，原课程与选区上下文不丢失。
- 助手纯图标操作悬停进出不改变消息高度；用户气泡点击复制有短暂描边反馈；折叠按钮反馈清楚且不触发整列重排。
- 反复拖动长会话滚动条无卡死回归。

## 本次不做

- 不做历史消息错峰挂载；只有真实长会话仍有首次打开卡顿证据时再加。
- 不做会话内搜索、消息编辑重发或对话分支。
