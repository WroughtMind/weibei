# webi 任务技能与渐进式披露

## 交付范围

新增九个任务技能，保留现有基础可视化、高级可视化和苏格拉底追问，共十二个内置技能。全部采用现有工具执行，不改变默认模型、推理强度、用户笔记或真实会话。

| 技能 | 核心职责 | 按需参考 |
|---|---|---|
| 网页搜索与事实核查 | 查询公开事实，核对关键前提，形成有证据的首次回答 | 统计比较；时间与事件状态 |
| 网页阅读与引用 | 读取正文、摘录、解释表格，保证证据对应 | 长页面与缺失内容；摘录与证据对应 |
| 课程资料检索 | 按已知位置或字面搜索定位课程材料和笔记 | 查询与范围选择；覆盖范围与 PDF |
| 材料精读与讲解 | 解释段落、概念、公式、图表与论证 | 公式与图表；论证与解释方法 |
| 多材料比较与综合 | 对齐条件、解释分歧，形成可追溯综合 | 分歧与可比性；综合写作与联系 |
| 笔记整理与修订 | 整理增量、准备修订稿，准确处理实际写入 | 编辑范围与内容组织；写入回执与关联 |
| 历史讨论回顾与纠错 | 读取真实消息，区分角色与版本，核实并更新旧结论 | 角色与时间线；纠错与结论更新 |
| 学习记忆与进度回顾 | 衔接学习、区分证据性质，记录持续变化 | 记录依据与更新；衔接与过期记录 |
| 出题练习与反馈 | 用户要求时出题、核对答案、针对实际表现反馈 | 题目与答案质量；反馈与互动 |

## 三层披露

1. **目录**：始终只注入技能编号与用途描述，供选择使用。
2. **核心流程**：匹配任务时通过 `load_skill` 读取该技能的 `SKILL.md`，取得基本流程、完成标准及场景参考入口。
3. **场景参考**：仅在相应分支出现时读取具体参考文件；不预读全部参考，也不把全部正文拼入系统提示。

例如，普通网页查询只需搜索技能入口；涉及球员年度统计的比较，再加载统计参考。已经提供网页地址的摘要任务直接使用网页阅读；不用为了走流程再搜索一次。

```json
{"id":"web-research"}
```

```json
{"id":"web-research","resource":"references/comparison.md"}
```

复用原有加载工具，新增可选 `resource` 参数。参考正文实际按需读盘，只允许读取注册技能自身 `references/` 目录下的 UTF-8 Markdown 文件；拒绝绝对路径、父目录跳转和符号链接越界。缺失文件明确报错，不返回入口正文冒充成功。

入口和各参考使用独立的加载编号、路径、内容摘要与字节数，分别写入既有加载记录。同一执行中去重；正常压缩或溢出压缩完成后清除去重集合，允许再次获取已被压缩移走的正文，保留历史加载记录。加载不会注册新工具或执行脚本。资源由现有 App 资源目录整体打包。

## 指引与代码的分工

系统提示保留来源真实性、隐私、写入回执和用户意图边界，并说明技能触发与按需读取方法。具体查询策略、比较方法、教学方法和任务完成标准放在技能中。权限、实际写入、加载范围由宿主代码和工具执行。

技能以当前工具能力为准：

- 原生网页搜索由模型服务提供，不虚构本地搜索工具。
- 课程搜索是连续文字匹配，支持材料、课程和全库范围；目录本身不提供正文证据。
- 材料图像仅能读取本轮提供的视觉资产，不扩展成任意 PDF 页或网页图片读取。
- 笔记工具向本轮目标追加内容或新建笔记；不能任选另一份笔记、原位替换或删除。修订稿完成不等于原文件已改。
- 课程知识档案记录用户自述掌握程度，学习记忆记录目标、困惑、进度、偏好与观察；同一事实不重复写两处。
- 练习和追问由用户选择，不由“我不懂”自动触发。

## 验证边界

自动检查验证资源可发现、引用可读取、三层内容进入模型请求的顺序、逐资源去重、加载记录、工具权限不变和路径隔离；使用本地模拟适配器，不调用外部模型、不读取真实学习数据。

技能格式验证不能证明模型会正确选择或执行技能。以下是后续真实模型验证应观察的行为；需保留检索结果、实际加载内容及首次回答，不能用无搜索的准备历史测试代替自然首问。

| 代表请求 | 应观察到的行为 |
|---|---|
| “比较今年甲乙的赛事表现” | 首轮对齐时间和赛事口径，核实重要赛事事实；缺项不补造排名 |
| “这篇网页能证明这个数字吗” | 读取相关正文及限定条件，引用支持具体断言 |
| 中文问题查英文课件 | 使用原文语言短词查找，零命中不立即声称未涉及 |
| “这个公式为什么成立” | 取得定义与假设，解释缺失步骤，区别原文与举例 |
| “两篇材料的结论为什么相反” | 核对条件与定义，保留仍未解决的实质分歧 |
| “补进旧笔记／替换旧错句” | 区分追加与原位替换，既不重复旧内容也不误报保存 |
| “你刚才说过这个吗” | 按真实角色与消息核对，随后独立核实事实 |
| “上次到哪了／我终于理解了” | 区分位置、用户自述和实际表现，读取后按证据更新 |
| “根据这一节出题并批改” | 依据材料出可解题目，接受等价答案，针对实际作答反馈 |

当前交付是技能内容、加载能力与本地自动验证；未把它标成已证明解决原始事实事故，也不包含正式 App 发布。

## 本地验证记录（2026-09-18）

| 检查 | 结果 |
|---|---|
| 九个新增技能的格式验证、目录描述与入口一致性、参考链接 | 通过 |
| `NativeSkillDisclosureTests` | 4 项通过：全部新技能与参考加载、路径隔离、真实循环分层披露、压缩后重读 |
| `NativeAgentRuntimeTests`、`NativeAgentReplayTests` | 50 + 9 项通过；合计 63 项相关检查通过 |
| 上下文压缩后的参考重读 | 修改前稳定复现“已加载但正文已丢失”；清除压缩后的去重集合后通过 |
| `WeiBeiNativeCheck --native-eval-self-check` | 离线检查通过，未使用真实凭证或联网模型 |
| 完整 `WeiBeiSafetyTests` | 未通过并中止：笔记动作出现 `securityScopeDenied`；WebKit 测试遇到沙箱服务拒绝及加载超时。不能计为全量回归通过 |
| 真实模型的选择、执行与回答质量 | 本分支尚未实验；按用户要求交由主会话组合最新配置后验证 |

本地 SwiftPM 构建关闭其嵌套构建沙箱以适应外层执行限制，并复用校验为同一 `Package.resolved` 的依赖副本；应用代码、测试逻辑和外层权限未放宽。初始构建与相关测试均在独立目录执行。
