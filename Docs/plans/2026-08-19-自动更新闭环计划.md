# 魏碑自动更新闭环计划

## 目标

把现有“设置页检查更新后打开浏览器”升级为应用内完整链路：魏碑默认自动检查更新；发现新版本后，在顶部栏左侧前进箭头右边显示下载图标，悬停可查看更新内容；点击后原位显示加载状态，下载、验证完成后自动安装并重开。设置页保留同等更新入口，并与顶部栏共享状态。

## 明确边界

- 不提供“自动检查更新”开关，自动检查固定开启。
- 没有更新时，顶部栏不显示更新控件，也不保留空白占位。
- 不使用远程推送服务；应用运行时由 Sparkle 按计划检查。
- 不默认后台静默下载。只有用户点击顶部栏或设置页更新按钮后才开始下载。
- 用户点击即代表同意本次下载与安装；下载完成后保存魏碑状态、退出、安装并重开，不再弹第二次确认。
- 系统因目录所有权要求管理员授权时，保留 macOS 原生授权提示。
- 不自行实现下载、挂载、覆盖和重启逻辑；使用 Sparkle 的签名校验与安装器。
- 本任务不创建标签、不上传正式安装包、不发布版本，也不合并 `main`。

## 用户状态

| 状态 | 顶部栏 | 设置页 |
| --- | --- | --- |
| 后台检查 / 没有更新 | 不显示，不占位 | “检查更新”；手动检查完成后显示“已是最新” |
| 发现更新 | 前进箭头右侧显示下载图标；悬停显示版本与 3–5 条更新内容 | 显示版本、更新内容和“立即更新” |
| 下载 / 校验 / 解压 / 安装 | 原位显示小型转圈，禁止重复点击 | 同步显示进行中状态 |
| 失败 | 恢复下载图标；悬停显示失败与重试提示 | 显示失败原因和重试入口 |
| 完成 | 保存数据后自动退出、安装、重开；新版启动后图标消失 | 新版显示“已是最新” |

## 实现结构

1. 通过 Swift Package Manager 接入 Sparkle 2，并在应用包中嵌入、签名其框架与辅助组件。
2. 新建应用级更新服务，由 `WeiBeiApp` 单例持有并注入主窗口与设置窗口；不放入 `WorkspaceStore`。
3. 更新服务实现 Sparkle 自定义用户界面协议：
   - 后台发现更新时保存版本、简短更新内容和等待用户选择的回调；
   - 用户点击任一更新入口后返回安装选择，Sparkle 开始下载；
   - 下载、解压、安装和失败回调驱动统一界面状态；
   - 下载完成后自动允许安装并重开。
4. 顶部栏在现有前进按钮之后按状态条件渲染更新控件，复用当前 24pt 图标按钮样式和系统悬停提示。
5. 设置页删除独立的 JSON 检测状态，改为消费同一个更新服务；保留手动检查、最新状态、版本和更新内容。
6. `Info.plist` 固定启用自动检查、关闭点击前的自动下载，配置 HTTPS 更新源和 Sparkle EdDSA 公钥。
7. 发布脚本在生成 DMG 后支持生成带 EdDSA 签名的 `appcast.xml`，并校验清单中的版本、构建号、下载地址、文件长度和签名均对应同一候选包。
8. 社区临时签名包正确嵌入并签名 Sparkle 组件；Developer ID 与苹果公证作为正式发行增强，不作为自动更新功能的实现阻塞。

## 首次迁移

已公开的 `1.0.0` 没有 Sparkle，无法原地获得新的更新器。首个包含 Sparkle 的桥接版仍由旧设置页指向安装包，用户手动覆盖一次；从桥接版到后续版本开始验证和使用应用内自动更新。新版本代码不保留两套更新实现。

## 共享文件占用

- `Package.swift`：Sparkle 依赖和应用目标链接。
- `Sources/WeiBei/App/WeiBeiApp.swift`：应用级更新服务所有权与窗口注入。
- `Sources/WeiBei/Views/ContentView.swift`：顶部栏更新控件。
- `script/build_and_run.sh`：将 Sparkle 框架正确嵌入应用包。
- `script/build_release_dmg.sh`：更新包签名与更新清单生成入口。

设置页文件、更新服务新文件和定向检查文件不属于共享核心面，但均限制在本任务范围内。预计在本分支编译、定向检查、应用包结构验证、双版本升级演练完成，并更新合并请求证据后释放占用。

## 验收

1. 无更新时顶部栏没有图标、没有空白占位；设置页可手动确认“已是最新”。
2. 隔离更新源出现更高构建号时，顶部栏前进箭头右侧出现下载图标；设置页同步显示同一版本。
3. 悬停内容来自更新清单，显示版本和简短变化，不泄露内部提交或签名信息。
4. 点击任一入口后两个界面同步进入加载状态；不会重复发起下载。
5. 错误更新签名、下载中断或清单无效时，不覆盖现有应用，界面恢复为可重试状态。
6. 下载成功后，未落盘笔记和工作区先保存，应用自动安装并重开；课程、Chat、笔记和阅读位置保持不变。
7. 打包后的 App 包含可加载的 Sparkle 框架与辅助组件；社区包和正式包各自通过对应签名结构检查。
8. 使用隔离更新源完成真实旧版到新版升级；公共更新源和正式 Release 不在本任务中改动。
