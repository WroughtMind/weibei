# 魏碑会话呈现的 Catalyst 接入方案

2026-09-09；沿用 [#452](https://github.com/WroughtMind/weibei/pull/452) 和 codex/uikit-catalyst-chat-lab。

**本次产品改动只集中在会话呈现。交付应是能正常使用的独立魏碑候选 App，而不是固定回答 Demo；不能据此扩大为课程、资料库、笔记、Agent 等业务的全面改造。** 此前 33c7b9ca 方案范围展开过宽，本版取代它；其中的功能盘点只作不丢功能的核对，不再作为逐项重建的施工清单。

代码依据是已合并 main@02555d8506504e9fd68374855d3cff87428c9eb6，本分支已通过 7511383f 合入。实验目录 Experiments/CatalystChatLab、独立目标和 scheme 已存在，继续使用。930c6035 会话实验的代码与原始证据保留；它不是完整魏碑。

## 一、必要改动

### 会话本身

保留已有 UIKit UICollectionView + MarkdownView / Litext UIKit 实现，接回原 StudySession、AgentMessage 和 WorkspaceStore。只处理会话显示所需的完整消息/富内容、定向流式更新、尺寸和阅读位置、选择复制、来源及消息动作。输入、发送、停止、重试、动作确认和历史恢复调用原业务入口，不再造 Agent 客户端或业务 store。

消息、有效解析/高亮/排版/尺寸与 cell 生命周期分开；滑动不反复处理未变历史，异步结果核对会话和消息代次。流式只改变化的消息或块，不整表重载，不重播旧段，停止/完成保留全文。前插、图片增高、改宽由同一会话控制器协调阅读锚点；不能通过固定延时反复滚到底、截断/折叠长答或减少富内容掩盖问题。

### 真实 Catalyst 绕不过去的宿主边界

**不是在原 AppKit 窗口里直接换一个 UICollectionView 就能完成。** 已核验的魏碑入口是 NSApplicationDelegate，分栏和阅读/笔记宿主是 NSViewRepresentable。本机 Xcode 26.6、macOS SDK 26.5 对真实 arm64-apple-ios16.0-macabi 的编译探针明确报 NSView、NSOpenPanel 不可用于 Mac Catalyst；原 macOS 目标强行导入 UIKit 也编译失败。不得用私有桥接、叠窗、截图转发或 AppKit 查看器换名绕过这个边界。

| 最小额外平台范围 | 为什么不能省 | 严格限制 |
| --- | --- | --- |
| 应用入口、窗口与分栏容器 | 原入口/常驻分栏依赖 AppKit；UIView 必须归属真正 Catalyst 的窗口和控制器 | 保持原工作区结构、布局状态和业务；只接 UIKit 场景、子控制器、必要菜单/焦点与保存生命周期，不设计新产品结构 |
| 阅读/笔记的系统视图桥 | 同一完整窗口里的 PDF、网页/文本阅读和笔记编辑器，当前通过 NSViewRepresentable/NSView 接入 | 只替换 UIKit PDFView/WKWebView/文本视图的宿主与回调；原文件处理、页面资源、编辑器协议、选区/来源和保存逻辑直接复用，不能重写读取器业务 |
| 系统操作、类型和资源接点 | 原 NSOpenPanel/NSAlert/NSEvent、颜色类型、SwiftPM 资源入口不适合此目标；Process.run 也被 SDK 标为不可用 | 文件选择/确认、键盘/剪贴板、颜色与资源按实际 API 适配；保留原操作选择和结果。PDF 取文仅适配现有有界助手启动，不新增辅助 App |

以上是平台适配范围，不是新的业务需求；但它确实超出「只修改会话文件」。若要求应用宿主和这些系统视图桥一行都不能动，与真实 Catalyst 同窗口交付无法同时满足。**在这项额外平台范围得到明确确认前，保留现有试改，暂停继续扩展宿主；不自行选择全面迁移，也不更换 UIKit 路线。**

当前试改按用途核验后再保留：OCR 图片、资源 bundle、目录 API、快捷键类型属于平台接点；把笔记写闸门迁出 store 的多余提取已取消，原唯一入口保留；未建新的简化 store。其他未提交平台试改已留在工作树，当前完整构建未通过，不宣称已接入。没有盲目 reset 或覆盖已有成果。

## 执行和验收

平台额外范围确认后：先完成必要接点的真实 Catalyst 构建，再把同一份会话实现接回原业务，最后用完整魏碑候选验证。先走资料打开 → 选区提问 → 真实流式/停止 → 来源返回 → 原笔记确认保存 → 重开恢复；这是一条防止接线丢功能的使用检查，不是重写这些模块的施工清单。正常 App 不显示实验按钮墙，固定重放仅作独立验证入口，不替代真实服务。

视觉以记录的已合并主线界面与设计资源为准，已查看入库的[三栏](../../website/assets/第二幕-真实三窗截图-去黑边.webp)和[纸面会话](../../website/assets/第三幕-真实截图-纸面-沉浸对话.webp)参照；历史截图不冒充当前实机清晰度证据。必须在同内容、同字号、同正文宽度、本机实际屏幕缩放下检查完整窗口、长答、改宽、流式和富内容。不能模糊、违和、主要内容裁切，不靠整窗缩放、正文/表格截图、缩字号或隐藏内容获得假效果；保留真实选字、跨段复制、右键、中文组词、焦点和附件横向滚动。

构建、链接、资源、签名、运行、数据安全、桌面手感与性能分别报告。复用与改动相关的少量原检查，不建大矩阵。性能使用 Release，首次与缓存后分开；组件毫秒、CPU 或显示回调不是呈现帧，不能换算 FPS。其他完整候选可用后再比较，差异不全归因于 UIKit。

画中画只操作本任务应用，不抢用户桌面或其他窗口。当前坐标拖动/滚轮仍报 noWindowsAvailable，辅助功能动作和截图可用；不能拿它们冒充鼠标/触控板验收。独立候选包必须能离开源码目录运行，附准确构建来源、实际检查/性能和剩余缺口；旧 930c6035 的 10/10 实验检查不自动适用于新业务路径。
