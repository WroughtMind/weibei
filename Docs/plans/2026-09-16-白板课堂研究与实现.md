# 魏碑白板课堂：研究、实现与验收

## 结论

白板课堂需要一套持续生成、播放、回执和恢复机制，单独移植教学提示词不能完成产品。魏碑复用已有的材料读取、语言模型和笔记保存入口：模型先生成教学计划，再逐个关键点生成讲解；编号、关键点完成与分页由本地管理，第一组到达即开讲；网页真正写完、说完才确认该步骤。

课堂编排与追问使用魏碑已有模型账号。系统朗读、中文动物语、文字排版、公式、关系图、Webi 和存档均在本地运行，不需要新增 API。只有显式选择云端语音时，才配置兼容 `/audio/speech` 的服务、模型、音色与密钥。

当前实现与候选包验证仍在进行。本文的“通过”只针对已记录的检查，不能等同于正式 App 已发布。

## 从材料到课堂

1. 在文稿标题旁进入白板，选择当前选文或 PDF 页范围。来源文字与页码始终保留；不支持读取的正文直接提示，不悄悄截断成成功。
2. 第一次请求只生成 3–6 个关键点，随后每个关键点生成 3–6 组。收到第一组即播放；当前段最后一组开始播放时预取下一段，未播队列最多一个关键点。追上生成时显示准备讲解的状态，Webi 思考。
3. 原生编排器只派发一步。网页用该动作的唯一编号和本次派发票据回执；旧回执、重复回执和失败回执都不能推进。
4. 同组语音真正开始时打开板书揭示门。默认一张卡配不超过 120 字的讲稿，只有对照时允许两张，三张及以上被拒绝。字迹进度跟随真实音频时钟或系统文字边界；最后一个书写单元等待语音结束，再完成动画。
5. 提问收到后课堂继续，问答栏自动展开。作答存为学生事件，答错时自动纠正，并撤回当前播放动作之后的所有待播内容。下一段带着作答、对错和纠正重新生成。
6. 追问回答直接出现在右栏，当前已播放的组不被打断；组结束后等待回答完成。回答完成后，以新事件重新授课，必要时补一张板书。用户主动暂停不会被完成回调自动开播。
7. 存档记录动作、已确认进度、回答、追问、页面、卡片、布局与版本。重开后默认暂停，从最后确认位置继续；当前未完成步骤重讲，不声称恢复到音频毫秒位置。已经展示却未作答的题目重新排到右栏顶部。

## 动作协议与执行边界

| 部分 | 实现 |
| --- | --- |
| 编码 | 换行分隔 JSON，每行一个完整动作；无效模型行丢弃并计数，继续接收；持久化与执行仍严格检查，网络中断不伪装为整段完成 |
| 动作 | `session_ready`、`new_page`、`new_column`、`board`、`graph`、`speak`、`highlight`、`circle`、`ask`、`group`、`keypoint_complete` |
| 编号 | 所有根动作和组内动作由本地分配唯一 `step_id`；板书编号本地分配，标注按标题或最近板书解析 |
| 板书与语音 | `board_content`、`spoken_text`；魏碑增加 `source_page/card_type`，用于原文定位及标题配色 |
| 提问 | `mode=choice/open`，选择题 2–4 个选项，`correct_index` 和解析；开放题不含选择题答案 |
| 坐标 | `rect:{x,y,w,h}`，归一化坐标，检查有限值与边界；也可用跨 Markdown 文本节点的 `snippet` |
| 关键点 | 教学计划包含 3–6 条；本地在段生成结束后补收尾，播放确认后才算已讲完。模型无需输出清单动作或完成标记 |
| 回执 | `action_step_complete` 必须匹配根动作编号和本次派发票据；失败单独上报 |
| 恢复 | 本地原子写入；存档按材料隔离。损坏数据报错并保留原文件，不覆盖为空课堂 |

动作顺序来自协议和回执。动画时长控制视觉效果，超时控制失败边界；二者都不能代替真实完成事件。

## 无框板面

卡片继续作为定位、标注和存档的容器，但没有背景、边框、阴影、圆角或类型角标。标题居中，类型只改变标题色；正文左对齐，依靠 32px 留白分隔。标题写完后，马克笔色条用 420ms 扫入。字体栈为 `Virgil, Kaiti SC, STKaiti, serif`。Virgil 原字体与 OFL 许可已打包，使用 `font-display: swap`；拉丁字符采用 Virgil，中文使用系统楷体。公式仍使用 KaTeX 的专用字体与度量，不能把普通文字字体替换误称为公式字体替换。

每个字符保持行内布局，仅通过透明度和模糊揭示，写完还原纯文本；公式作为整体出现。独立板书或静音字幕的揭示速度是 `clamp(2880ms/单元数,18ms,50ms)`；配音卡片按实际语音进度分配书写单元，末字不早于语音结束。SVG 笔尖跟随已揭示字符，完成后淡出；开启系统“减少动态效果”时取消非必要动画。

页面内使用两栏，高度变化触发下方板书重排和栏水位更新。关系图宽为普通板书的 1.5 倍，同时占用两栏水位以防重叠；总结使用整栏宽。满栏后换栏、再换页，相机平滑跟随 450ms。Mermaid 11.16.1 使用手绘风格、手写字体和柔和主题色。圈画用 920ms 描边，高亮用 1s 扫入，深浅色分别适配。

## 语音与 Webi

### 统一朗读

完成的助手回复、文稿、笔记和对应选文均可朗读。普通朗读首次默认系统中文；白板默认中文动物语，两种声音偏好独立，语速和云服务配置共用。每处入口可以配置云端地址、模型、音色及密钥，无需先进入白板。

朗读从现有正文或编辑器最新快照读取，不额外请求语言模型、不改写原文。Markdown 解析后只读可见文字；公式、代码明确略过，链接只读文字，不念内部来源编号。长文逐段合成和播放。暂停、继续、停止和状态共用同一个控制器；新声音取得播放权时，旧声音停止或白板暂停，未完成课堂步骤不会因此获得回执。

系统语音使用实际开始、文字边界和结束回调；云端及动物语使用单个音频元素的真实 `playing/ended/currentTime`。变速保持音高。静音课堂显示并逐字揭示讲稿，不会瞬间执行整堂课。

### 本地中文动物语

采用 [animalese-tts 1.1.3](https://github.com/izure1/animalese-tts) 与 [pinyin-pro 3.29.4](https://github.com/zh-lx/pinyin-pro)，两者为 MIT。中文音节来自 [audio-cmn 固定提交](https://github.com/hugolpz/audio-cmn/tree/ff9ed3d0c631195bd2c06f39450f3264c7124040/64k/syllabs)，全部 1,707 个原始 MP3 已核对 Git blob 哈希及文件内 CC-BY-SA-3.0 声明。

录音署名 Chen Wang，整理与版权记录为 Wang Chen、Lopez Hugo、Vion Nicolas（2013）。魏碑裁剪首尾静音、归一化音量、转为 16kHz 单声道，按首字母合为 23 组，使用系统 Opus 编码器以 10kbps 写入 CAF。全部声音、音节索引与许可共 1,724,598 字节，保留全部 1,707 个原始音节和声调；运行时由系统解码器按需解码，完全离线。此编码为有损音频压缩，不宣称波形与原文件相同；字、音节和口型的时序从实际解码样本重新计算。上游删除了重复的轻声录音，因此轻声使用第一声采样；没有使用英文语音或游戏原声代替中文。

数字、百分号、小数点和拉丁字母使用中文念法，多音字按整段拼音分析。字符字幕和每个音节的时间边界均由实际合成样本数计算，再由音频时钟驱动。板书与讲稿不一定逐字相同，板书仍采用步骤同步；不声称二者逐字对齐。

修改后的声音素材包保持 [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/)；来源、修改说明与许可全文随包保存。维护时运行 `script/build_chinese_voice.py`，需要 macOS Core Audio、numpy 与 soundfile；普通构建及运行无需下载声音或这些 Python 依赖。网页只能向原生读取固定首字母对应的内置声音包，不能提供任意 URL 或文件路径。

### Webi 课堂伙伴

仅打包两张透明 WebP 动作图、一张独立口型 PNG 和素材清单：共 4 文件、471,120 字节，小于 500KiB。包含 8 动作、32 身体帧和 8 嘴型，不打包原稿、预览动图或展示压缩包，无新增动画库。白板铺满可用宽度，Webi 浮在右下角，不预留整列空白；收起时不移动板书，图像区域允许手写和滚动穿透，仅收起按钮接收点击。底部字幕避开伙伴。普通朗读在朗读菜单显示伙伴，可收起。

动物语口型跟随实际音节区间，口型形状按拼音近似选择；系统语音仅按现有文字边界回调表现，不宣称音素级精确对嘴。暂停闭口，隐藏或收起释放图片引用并停止动画计时。压缩文件大小不能代替解码内存峰值，实际 Catalyst 峰值仍需实测。候选角色的最终视觉确认仍由用户决定。

## 超时、隐私与失败处理

| 操作 | 完成依据 | 失败上限 |
| --- | --- | --- |
| 排版 | 字体、公式/图示完成且网页绘制 | 30 秒 |
| 板书揭示 | 字符/公式动画实际结束 | 独立卡 `min(30秒,4秒+24ms×字符数)`；语音配合卡为语音上限加 3 秒 |
| 揭示门 | 系统语音开始或音频 `playing` | 8 秒 |
| 课堂语音 | 系统结束或音频 `ended` | 180 秒 |
| 高亮、圈画 | 动画实际结束 | 4 秒 |
| 页、栏与进度 | 实际绘制 | 4 秒 |
| 提问 | 原生收到并记录题目后立即回执 | 4 秒仅作异常兜底；不依赖右栏出现或作答 |
| 本地合成 | 音节解码与样本拼接完成 | 30 秒；资源加载 15 秒 |
| 普通朗读 | 实际媒体时钟持续推进 | 停滞 15 秒报错；系统回调停滞 30 秒报错 |

暂停时间不计入课堂失败时限。超时暂停并提示，不切换声音或伪造完成。取消、重播和换来源都会隔离旧回调。云端凭据留在既有存储并绑定端点，拒绝重定向，响应限制 32MB；存档中没有密钥。网页禁止联网与 iframe，Markdown 和 SVG 净化后渲染，不执行模型提供的 HTML 或代码。

用户手写批注层已按后续工单追加。AI 生图、任意 HTML 动画、浏览器语音检测、双向 PCM 与全双工打断不在本期；当前提供文字追问和主动暂停。

## 生成上下文与应用体积

关键点生成与追问共用一个上下文出口。只带已教卡片的标题、类型和所属关键点，省略正文、图形源码和讲稿；携带教学计划、已完成点、自上次生成以来的学生事件及最近四条更早事件。所有请求都记录实际调用结果、时长、输入文本字节与服务端 token；取消和废弃请求也计入成本，未返回 usage 时标记缺失。

用户明确要求完整应用仍低于 30,000,000 字节，不能放宽检查。初轮远端实包失败：arm64 为 78,195,618 字节，Intel 为 79,435,625 字节。除音频编码外，普通朗读和白板共用一份拼音/合成引擎；编辑器、公式和三维引擎采用已有无损脚本压缩机制；代码着色引擎在 JavaScriptCore 内无损解包。主应用发布构建去掉无用途的导出表和符号，完整 dSYM 独立保留，原生窗口桥接包的导出设置不变。最终数字必须取重建并签名的完整 App，输入文件差额不作为通过结论。
