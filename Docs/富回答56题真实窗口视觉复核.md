## 五个共性问题

1. **空回答壳**：多题只剩“结论”标题或“回放没有可渲染正文”，正文和安全替代均未显示。
2. **误拒导致能力断流**：至少 9 个富回答场景已有真实 Pi 输出，却被固定 family、intent、关键词或低级图元合同反复拒绝，最终退回失败文本。
3. **宿主仍会把内联内容当整页**：部分题出现重复文档页、第三栏、横向挤压和大片空白，生成式 UI 没有自然长在回答流里。
4. **互动证据失真**：5 题操作前后画面相同，截图链存在但学习状态没有可见改变。
5. **专业表达出口不足**：地图、真实图像叠加、分子三维关系、现金流敏感性等场景要么缺失，要么退化为抽象点线和文字排版。
