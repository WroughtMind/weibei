# 构建编号

构建号使用 UTC 时间 `yyyyMMdd.HHmm.ss`，例如 `20260909.1530.27`。应用设置中按电脑本地时区显示构建时间；版本号与源码提交仍保留，用于问题追溯。构建时间表示打包批次开始时间，不是提交时间。

本地打包自动生成编号；同批多个产物通过环境变量 `WEIBEI_BUILD_NUMBER` 传入同一个编号。持续集成与正式发布分别在批次开始时生成一次，两种芯片的安装包共用。打包后的校验读取固化编号，不重新生成时间。

本地重新打包时，编号必须大于已有 dist 安装包；正式发布时必须大于上一正式版本各更新源里的编号。时钟倒退或编号重复时停止，不自动编造递增时间。正式发布汇总时再次核对两种芯片更新源与批次编号一致。

检查：`python3 script/check_build_number.py`；时间显示检查由 macOS 应用检查任务运行。
