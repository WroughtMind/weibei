# 魏碑 1.0.0 发布计划

这是魏碑未来 `1.0.0` 的发布计划，不代表当前源码已经达到或发布 `1.0.0`。仓库已经公开；本分支先把品牌、安装包和校验链做完整，实际产物版本始终读取仓库根目录的版本文件（当前为 `0.1.0`），不会在未合入整合线、未完成真实窗口验收和再分发复核前创建正式标签或 Release。

## 本次交付

- 接入 `WeiBei-Design-System-v0.1.1.zip` 的完整设计系统、App 图标、Logo、宣传图和 DMG 视觉；
- 按版本文件构建 Apple 芯片版 `WeiBei-<版本>-macOS-arm64.dmg`，内含“魏碑”与“应用程序”快捷入口；
- 同时生成 SHA-256 校验文件，Homebrew Cask 与人工下载共用同一份 DMG；
- 支持两条信任链：当前可用的社区未公证构建，以及未来配置 Developer ID 后的签名与苹果公证构建；
- README 说明 DMG、Homebrew、源码三种安装路径和首次启动方法。

## 当前发布边界

- 社区构建采用 ad-hoc 签名，尚未经过 Apple 公证；macOS 首次启动会要求用户明确确认。
- 只提供 Apple 芯片（arm64）预编译包，最低系统为 macOS 14。
- 不关闭全局 Gatekeeper；只采用 Apple 官方的“仍要打开”单应用例外，终端备用命令也只处理 `/Applications/魏碑.app`。
- Homebrew 只是安装和升级入口，不替代 Apple 签名或公证。
- 项目源代码采用 `AGPL-3.0-only`；品牌与项目媒体使用单独条款。完整第三方二进制再分发材料仍需维护者在正式 Release 前确认。

## 完成条件

只有在完整构建、自检、DMG 挂载、应用图标、版本元数据、签名结构、SHA-256 与 Homebrew Cask 安装路径均通过后，才可把本分支交给整合发布任务。草稿合并请求、局部脚本通过或本地安装包都不等于已经正式发布。
