# 魏碑 1.0.0

魏碑 1.0.0 是第一个稳定社区版本：把课程资料、证据问答、学习记忆和真实 Markdown 笔记放进同一个 macOS 工作台，同时保持文件由用户掌握。

## 本次可以做什么

- 把本地文件夹原地登记为课程，阅读和搜索 PDF、HTML、Markdown、图片与常见文稿；
- 让 Agent 按当前课程和材料回答，显示来源并跳回原文；
- 把回答整理成待确认的笔记或关系操作，不静默改写正式笔记；
- 按课程保存对话、阅读位置、学习记忆和材料关系，重开后继续；
- 直接编辑课程文件夹里的 Markdown 笔记，并提供原子写入、恢复副本和课程目录边界保护；
- 使用渐进式 Markdown 对话、复制、重新生成、Slash 命令与生成式互动内容；
- 在纸面、墨石等主题以及课程学习和纯净写作布局之间切换。

1.0.0 还集中修复了课程资料拒开、侧边栏和文稿列表重复扫描、WebKit 阅读器高频通信、悬浮面板布局循环、笔记写回与课程状态并发等问题。

## 产品边界

- 笔记是一条路径上的一份真实 Markdown；魏碑不承诺与外部编辑器进行实时双向协作。
- 只提供 Apple 芯片版，要求 macOS 14 或更高版本。
- 课程文件与索引以本机为主；实时模型回答仍可能需要网络和可用的模型凭据。
- 大型或难解析资料会明确显示部分索引或不完整状态，不伪装成完整读取。

## 下载与首次打开

正式 Release 提供：

- `WeiBei-1.0.0-macOS-arm64.dmg`
- `WeiBei-1.0.0-macOS-arm64.dmg.sha256`

下载后可运行 `shasum -a 256 -c WeiBei-1.0.0-macOS-arm64.dmg.sha256` 核对安装包，把“魏碑”拖入“应用程序”。

本次采用社区临时签名，尚未经过 Apple 公证。若 macOS 首次阻止打开，请先尝试打开一次，再到“系统设置 → 隐私与安全性”中选择“仍要打开”。这只为魏碑建立单应用例外，不会关闭系统的整体安全保护。
