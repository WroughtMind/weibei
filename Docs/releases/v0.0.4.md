# 魏碑 0.0.4

## 功能

- **对话引用**　选中对话文字后，可以把片段放进输入框，预览引用并返回原消息。摘录会保留缩进和换行。 ([#544](https://github.com/WroughtMind/weibei/pull/544))

## 改进

- **阅读空间**　阅读时顶栏图标自动收起，移入鼠标即可显示，正文位置保持稳定。顶栏、阅读控件和学习记忆图标也更新了样式。 ([#552](https://github.com/WroughtMind/weibei/pull/552), [#553](https://github.com/WroughtMind/weibei/pull/553), [#554](https://github.com/WroughtMind/weibei/pull/554), [#555](https://github.com/WroughtMind/weibei/pull/555))
- **课程与笔记**　已登记的课程即使历史问答或进度暂时读不全，也能打开资料；原状态文件会保留。遇到笔记保存冲突时，确认按钮会写明将执行的动作。 ([#556](https://github.com/WroughtMind/weibei/pull/556))

## 修复

- **菜单与快捷键**　修复 macOS 14、15 上设置和部分工作区菜单命令不可用的问题，以及连续调整对话浮窗大小时宽度跳变的问题。 ([#551](https://github.com/WroughtMind/weibei/pull/551))
- **更新说明**　修复更新说明浮窗遮挡点击的问题。关闭后重新打开，也能从顶栏和课程页继续操作。 ([#550](https://github.com/WroughtMind/weibei/pull/550))
- **聊天与 PDF**　连接预检失败后可以继续尝试发送。修复 PDF 后台读取可能遗漏末尾结果，以及部分系统上计时可能导致崩溃的问题。 ([#556](https://github.com/WroughtMind/weibei/pull/556))

## 下载与安装

需要 **macOS 14 或更新版本**。在“苹果菜单 → 关于本机”中查看芯片类型，选择对应安装盘：

| 你的 Mac | 安装包 |
|---|---|
| Apple 芯片，包括 M 系列 | `WeiBei-0.0.4-macOS-arm64.dmg` |
| Intel 处理器 | `WeiBei-0.0.4-macOS-x86_64.dmg` |

安装包位于下方发布资产中。双击安装盘，将“魏碑”拖入“应用程序”即可。每份安装包旁的 `.sha256` 用于校验完整性。

从 0.0.3 升级可在应用内检查更新，沿用原资料库，无需重新导入课程与笔记。使用早期测试更新公钥的开发版，仍需手动安装一次公开版。

本版本使用临时签名，**未经 Apple 公证**。首次打开如提示无法验证开发者，请确认安装包来自 [本项目发布页](https://github.com/WroughtMind/weibei/releases) 且校验值一致，再按 [Apple 官方指引](https://support.apple.com/zh-cn/102445) 至“系统设置 → 隐私与安全性”允许打开。若提示文件损坏或恶意内容，请停止安装并反馈。

支持通过 [Homebrew](https://github.com/taekchef/homebrew-tap) 自动匹配架构安装：

```bash
brew install --cask taekchef/tap/weibei
```

## 使用与限制说明

- 大文件与扫描件可能显示部分索引状态；检索和回答以实际完成索引的内容为准。
- 在线模型取决于服务商与网络。未连接模型时仍可正常离线阅读与记笔记。详见 [隐私说明](https://github.com/WroughtMind/weibei/blob/main/PRIVACY.md)。
