# 魏碑 0.0.3

## 功能

本次沿用 0.0.2 的应用功能，无新增功能。

## 改进

- **版本发布**：减少安装包的重复构建，自动衔接检查、发布与下载渠道核验。([#545](https://github.com/WroughtMind/weibei/pull/545))
- **下载渠道**：发布后自动核对官网下载入口，以及 Apple 芯片和 Intel Mac 的 Homebrew 安装结果。([#545](https://github.com/WroughtMind/weibei/pull/545))

## 修复

本次无新增的应用功能修复。

## 下载与安装

需要 **macOS 14 或更新版本**。在“苹果菜单 → 关于本机”中查看芯片类型，选择对应安装盘：

| 你的 Mac | 安装包 |
|---|---|
| Apple 芯片，包括 M 系列 | `WeiBei-0.0.3-macOS-arm64.dmg` |
| Intel 处理器 | `WeiBei-0.0.3-macOS-x86_64.dmg` |

安装包位于下方发布资产中。双击安装盘，将“魏碑”拖入“应用程序”即可。每份安装包旁的 `.sha256` 用于校验完整性。

从 0.0.2 升级可在应用内检查更新，沿用原资料库，无需重新导入课程与笔记。使用早期测试更新公钥的开发版，仍需手动安装一次公开版。

本版本使用临时签名，**未经 Apple 公证**。首次打开如提示无法验证开发者，请确认安装包来自 [本项目发布页](https://github.com/WroughtMind/weibei/releases) 且校验值一致，再按 [Apple 官方指引](https://support.apple.com/zh-cn/102445) 至“系统设置 → 隐私与安全性”允许打开。若提示文件损坏或恶意内容，请停止安装并反馈。

支持通过 [Homebrew](https://github.com/taekchef/homebrew-tap) 自动匹配架构安装：

```bash
brew install --cask taekchef/tap/weibei
```

## 使用与限制说明

- 大文件与扫描件可能显示部分索引状态；检索和回答以实际完成索引的内容为准。
- 在线模型取决于服务商与网络。未连接模型时仍可正常离线阅读与记笔记。详见 [隐私说明](https://github.com/WroughtMind/weibei/blob/main/PRIVACY.md)。
