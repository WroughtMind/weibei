# 魏碑 0.0.3

本次为维护版本，沿用 0.0.2 的应用功能，更新安装包构建与校验流程。

## 从 0.0.2 更新

可以在魏碑中检查更新，也可以退出应用后，下载对应芯片的安装盘并替换“应用程序”中的魏碑。升级沿用现有资料库和更新签名公钥，无需重新导入课程与笔记。

早期采用测试更新公钥的开发版仍需手动安装一次公开版。

## 下载与安装

需要 **macOS 14 或更新版本**。在“苹果菜单 → 关于本机”中查看芯片类型，选择对应安装盘：

| 你的 Mac | 安装包 |
|---|---|
| Apple 芯片，包括 M 系列 | `WeiBei-0.0.3-macOS-arm64.dmg` |
| Intel 处理器 | `WeiBei-0.0.3-macOS-x86_64.dmg` |

安装包位于本页下方的发布资产中。双击安装盘，将“魏碑”拖到“应用程序”，然后从“应用程序”打开。每份安装盘旁的 `.sha256` 文件用于核对下载完整性。

本版本使用临时签名，**未经 Apple 公证**。首次打开若系统提示无法验证开发者，请先确认安装包来自 [本项目发布页](https://github.com/WroughtMind/weibei/releases)、校验值一致，再按 [Apple 的单个应用打开说明](https://support.apple.com/zh-cn/102445)，到“系统设置 → 隐私与安全性”确认是否打开。若系统提示包含恶意内容或文件已损坏，请停止安装并反馈，不要关闭系统安全检查。

也可以通过 [Homebrew 安装渠道](https://github.com/taekchef/homebrew-tap)安装，自动选择对应芯片：

```bash
brew install --cask taekchef/tap/weibei
```

发布资产中的调试符号压缩包用于分析崩溃，不需要安装。

## 使用与已知限制

- 当前安装包未经 Apple 公证，首次打开可能需要在系统设置中单独允许。
- 大文件与扫描件可能显示部分索引状态；搜索和回答能引用的范围以实际完成索引的内容为准。
- 在线模型是否可用取决于服务商、账号与网络。未连接模型时仍可阅读本地资料和编辑笔记。在线模型会收到完成问题所需的相关摘录，网页及远程图片也可能联网；详见 [隐私说明](https://github.com/WroughtMind/weibei/blob/main/PRIVACY.md)。
