# 魏碑 0.0.5

## 功能

- **划词翻译与双语阅读**　选中文字可在选区附近查看译文。开启双语后，阅读器随滚动或翻页逐段显示译文，可使用现有模型连接或选择一条 API Key 连接。 ([#573](https://github.com/WroughtMind/weibei/pull/573))
- **笔记导出 PDF**　在魏碑内预览笔记，调整纸张、字号与页码，再导出 PDF。表格和长段落可跨页，支持公式与图表。 ([#562](https://github.com/WroughtMind/weibei/pull/562)、[#571](https://github.com/WroughtMind/weibei/pull/571))
- **全局强调色**　在设置的「界面」中切换色系并微调明暗。侧栏、阅读、笔记和对话随所选配色更新。 ([#561](https://github.com/WroughtMind/weibei/pull/561))

## 改进

- **文稿纸签**　鼠标移到阅读浮栏的纸签上可展开、切换或关闭已打开的文稿。切回时恢复上次页码或章节。 ([#574](https://github.com/WroughtMind/weibei/pull/574))
- **课程侧栏**　点击整行展开课程，可同时展开多门课。搜索结果按课程分组，导入前可选课程和资料类型。 ([#558](https://github.com/WroughtMind/weibei/pull/558))
- **工作区与全屏**　文稿、笔记和对话栏可分别开关，保留拖动后的栏序。全屏时移到顶部可唤出导航，展开和收起沿用统一动效。 ([#564](https://github.com/WroughtMind/weibei/pull/564)、[#570](https://github.com/WroughtMind/weibei/pull/570)、[#572](https://github.com/WroughtMind/weibei/pull/572))
- **旧笔记与课程**　读取和导出笔记时保留原始 Markdown。旧课程保存后重开，依然保留已登记的资料关联。 ([#572](https://github.com/WroughtMind/weibei/pull/572))
- **对话引用与提示**　引用贴着输入框显示，可展开全文或返回原消息。复制提示留在选区工具条，较长的状态提示会换行。 ([#560](https://github.com/WroughtMind/weibei/pull/560))

## 修复

- **笔记回顶与保存**　修复打字机模式回顶时首段不可见、切回窗口重载未变动笔记，以及暂时等不到编辑器回应就误报保存失败的问题。 ([#563](https://github.com/WroughtMind/weibei/pull/563)、[#571](https://github.com/WroughtMind/weibei/pull/571))
- **选区追问**　修复发送后输入框残留草稿，以及回答重新排版时浮窗跳位的问题。 ([#559](https://github.com/WroughtMind/weibei/pull/559))

## 下载与安装

需要 **macOS 14 或更新版本**。在「苹果菜单 → 关于本机」中查看芯片类型，再从发布资产中选对应安装盘。

| 你的 Mac | 安装包 |
|---|---|
| Apple 芯片，包括 M 系列 | `WeiBei-0.0.5-macOS-arm64.dmg` |
| Intel 处理器 | `WeiBei-0.0.5-macOS-x86_64.dmg` |

打开安装盘，将「魏碑」拖入「应用程序」。每份安装包旁的 `.sha256` 用于校验完整性。公开版 0.0.4 可在应用内检查更新，继续使用原资料库。

本版本使用临时签名，未经 Apple 公证。首次打开如提示无法验证开发者，请先确认安装包来自项目发布页并核对校验值，再在「系统设置 → 隐私与安全性」允许打开。 [Apple 官方指引](https://support.apple.com/zh-cn/102445)

也可以用 Homebrew 自动选择对应架构。

```bash
brew install --cask taekchef/tap/weibei
```

## 使用与限制说明

- 翻译使用所选模型服务。双语阅读支持 PDF、HTML、Markdown、TXT、Word 和 PowerPoint，译文会随实际阅读位置加载。 [隐私说明](https://github.com/WroughtMind/weibei/blob/main/PRIVACY.md)
- 大文件与扫描件可能显示部分索引状态，检索和回答以实际完成索引的内容为准。
