# 发布与安装

魏碑的首个版本为 **0.0.1**，支持 macOS 14 及以上的苹果芯片和英特尔 Mac。[首版说明](v0.0.1.md)介绍功能、安装步骤和已知限制。

实际可下载版本以 [GitHub Releases](https://github.com/WroughtMind/weibei/releases) 中已公开的安装包为准。发布页尚无版本时，表示候选仍在准备；云端检查中的候选包和仓库截图不代表已经公开发布。

安装时选择自己芯片对应的安装盘，打开后把“魏碑”拖到“应用程序”。安装包未经 Apple 公证；首次打开步骤见[首版说明](v0.0.1.md#下载与安装)。

参与开发可按照[项目首页](../../README.md#从源码运行)从源码构建。双架构候选、完整发布集合与公开操作见[发布流程](dual-architecture.md)。
