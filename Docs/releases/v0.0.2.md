# 魏碑 0.0.2

这一版集中修复首次使用、笔记保存和窗口交互，并把 Marp 课件的翻页栏统一为魏碑样式。

## 这一版更新了什么

- **首次使用更顺畅。** 尚未连接模型时，可以直接从聊天区添加连接，保留订阅账号登录与 API 密钥两种方式。资料库创建失败后，可以重试或另选位置；已有资料库暂时无法访问时，仍保留原库的重连入口。
- **笔记保存与退出更稳妥。** 修复自动保存、切换笔记和退出时的异步等待，减少保存冲突造成的界面阻塞，避免旧的保存结果替换后续编辑。修复资料目录监听停止时的释放问题。
- **模型连接更独立。** 修改凭据时按任务归属取消关联请求，减少无关会话被打断。
- **顶栏与会话操作更一致。** 修复顶栏按钮点按，以及搜索框聚焦和关闭设置后的布局跳动。会话选区的复制、引用改用图标，保留悬停说明，并跟随当前外观和文字大小。
- **课件翻页使用魏碑样式。** Marp 课件保留前后翻页与页码显示，首末页正确禁用对应按钮；课件导出的全屏、演讲者控制栏不再混入阅读界面。
- **安装指引更清晰。** 修正显示隐藏文件时安装盘辅助文件遮挡说明的问题，官网提供安装与首次打开的操作指引。

## 从 0.0.1 更新

可以在魏碑中检查更新，也可以退出应用后，下载对应芯片的安装盘并替换“应用程序”中的魏碑。课程与笔记保存在独立的资料目录中，升级沿用现有资料库和更新签名公钥，无需重新导入。

早期采用测试更新公钥的开发版仍需手动安装一次公开版，之后沿用正式更新公钥校验安装包。

## 下载与安装

需要 **macOS 14 或更新版本**。在“苹果菜单 → 关于本机”中查看芯片类型，选择对应安装盘：

| 你的 Mac | 安装包 |
|---|---|
| Apple 芯片，包括 M 系列 | `WeiBei-0.0.2-macOS-arm64.dmg` |
| Intel 处理器 | `WeiBei-0.0.2-macOS-x86_64.dmg` |

安装包位于本页下方的发布资产中。双击安装盘，将“魏碑”拖到“应用程序”，然后从“应用程序”打开。每份安装盘旁的 `.sha256` 文件用于核对下载完整性。

本版本使用临时签名，**未经 Apple 公证**。首次打开若系统提示无法验证开发者，请先确认安装包来自 [本项目发布页](https://github.com/WroughtMind/weibei/releases)、校验值一致，再按 [Apple 的单个应用打开说明](https://support.apple.com/zh-cn/102445)，到“系统设置 → 隐私与安全性”确认是否打开。若系统提示包含恶意内容或文件已损坏，请停止安装并反馈，不要关闭系统安全检查。

也可以通过 [Homebrew 安装渠道](https://github.com/taekchef/homebrew-tap)安装，自动选择对应芯片：

```bash
brew install --cask taekchef/tap/weibei
```

发布资产中的调试符号压缩包用于分析崩溃，不需要安装。命令行安装描述文件对应上述 Homebrew 安装渠道。

## 使用与已知限制

- 当前安装包未经 Apple 公证，首次打开可能需要在系统设置中单独允许。
- 大文件与扫描件可能显示部分索引状态；搜索和回答能引用的范围以实际完成索引的内容为准。
- 在线模型是否可用取决于服务商、账号与网络。未连接模型时仍可阅读本地资料和编辑笔记。在线模型会收到完成问题所需的相关摘录，网页及远程图片也可能联网；详见 [隐私说明](https://github.com/WroughtMind/weibei/blob/main/PRIVACY.md)。
