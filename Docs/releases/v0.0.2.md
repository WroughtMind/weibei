# 魏碑 0.0.2

## 功能
- **聊天区直接接入模型**：未连接模型时，可在对话框直接添加入口，支持账号登录与 API 密钥。([#539](https://github.com/WroughtMind/weibei/pull/539))
- **资料库异常引导**：启动时若建库失败或原库失联，支持原地重试、重选目录或重新连接。([#539](https://github.com/WroughtMind/weibei/pull/539))
- **Homebrew 安装**：支持 `brew install --cask taekchef/tap/weibei` 安装与更新。([#531](https://github.com/WroughtMind/weibei/pull/531), [#536](https://github.com/WroughtMind/weibei/pull/536))

## 改进
- **顶栏交互**：修复顶栏偶发点击无响应，统一分栏悬停动效，消除搜索框聚焦时的布局跳动。([#532](https://github.com/WroughtMind/weibei/pull/532), [#543](https://github.com/WroughtMind/weibei/pull/543))
- **Marp 课件阅读**：翻页栏改用原生样式与页码指示，隐藏课件自带的全屏与演讲者冗余控件。([#542](https://github.com/WroughtMind/weibei/pull/542))
- **会话选区胶囊**：文字选中浮动栏改用轻量纯图标，自适应当前主题材质与字号。([#541](https://github.com/WroughtMind/weibei/pull/541))
- **模型凭据隔离**：修改设置时仅中断当前关联任务，不影响其他会话。([#535](https://github.com/WroughtMind/weibei/pull/535))

## 修复
- **笔记切换与保存**：修复切换笔记卡顿与快照冲突，确保保存完成再切走，防止编辑内容丢失。([#534](https://github.com/WroughtMind/weibei/pull/534))
- **资料目录监听**：修复监听器反复启停时的资源释放问题。([#533](https://github.com/WroughtMind/weibei/pull/533))
- **安装盘界面**：修复开启“显示隐藏文件”时背景资源遮挡操作指引的问题。([#538](https://github.com/WroughtMind/weibei/pull/538))

## 下载与安装

需要 **macOS 14 或更新版本**。在“苹果菜单 → 关于本机”中查看芯片类型，选择对应安装盘：

| 你的 Mac | 安装包 |
|---|---|
| Apple 芯片，包括 M 系列 | `WeiBei-0.0.2-macOS-arm64.dmg` |
| Intel 处理器 | `WeiBei-0.0.2-macOS-x86_64.dmg` |

安装包位于下方发布资产中。双击安装盘，将“魏碑”拖入“应用程序”即可。每份安装包旁的 `.sha256` 用于校验完整性。

本版本使用临时签名，**未经 Apple 公证**。首次打开如提示无法验证开发者，请按 [Apple 官方指引](https://support.apple.com/zh-cn/102445) 至“系统设置 → 隐私与安全性”允许打开。若提示文件损坏或恶意内容，请停止安装并反馈。

支持通过 [Homebrew](https://github.com/taekchef/homebrew-tap) 自动匹配架构安装：

```bash
brew install --cask taekchef/tap/weibei
```

## 使用与限制说明

- 大文件与扫描件可能显示部分索引状态；检索和回答以实际完成索引的内容为准。
- 在线模型取决于服务商与网络。未连接模型时仍可正常离线阅读与记笔记。详见 [隐私说明](https://github.com/WroughtMind/weibei/blob/main/PRIVACY.md)。
