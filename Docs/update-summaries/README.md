# 应用内更新摘要

正式发版前新增 `v版本号.md`。普通更新亮点写 3–5 条面向用户的短句；如果存在破坏性变化、迁移步骤或已知问题，必须按下面的固定标题逐条完整保留，不计入 3–5 条亮点，也不能为了缩短摘要而省略：

```markdown
- 顶部栏可以直接下载新版本
- 设置页可以检查并安装更新
- 修复若干稳定性问题

## 破坏性变化
- 逐条写全所有破坏性变化

## 迁移
- 逐条写全所有需要用户处理的迁移步骤

## 已知问题
- 逐条写全所有已知问题
```

没有对应内容时可以不写该分类；只要存在，就必须使用上述标题并完整列出。

这里的内容只用于魏碑内的更新提示；GitHub Release 继续使用 `Docs/releases/` 下的完整发布说明。
