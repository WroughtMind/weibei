### 功能

- 选中对话文字后，可以把片段放进输入框，预览引用并返回原消息。摘录会保留缩进和换行。 (#544)

### 改进

- 阅读时顶栏图标自动收起，移入鼠标即可显示，正文位置保持稳定。顶栏、阅读控件和学习记忆图标也更新了样式。 (#552, #553, #554, #555)
- 已登记的课程即使历史问答或进度暂时读不全，也能打开资料；原状态文件会保留。遇到笔记保存冲突时，确认按钮会写明将执行的动作。 (#556)

### 修复

- 修复 macOS 14、15 上设置和部分工作区菜单命令不可用的问题，以及连续调整对话浮窗大小时宽度跳变的问题。 (#551)
- 修复更新说明浮窗遮挡点击的问题。关闭后重新打开，也能从顶栏和课程页继续操作。 (#550)
- 连接预检失败后可以继续尝试发送。修复 PDF 后台读取可能遗漏末尾结果，以及部分系统上计时可能导致崩溃的问题。 (#556)
