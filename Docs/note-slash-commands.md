# 笔记 Slash 快捷命令

笔记“原地写作”模式支持在任意合格空段落开头输入 `/` 打开块命令菜单，不要求该空段落位于文档或父容器末尾。菜单跟随光标定位，空间不足时自动翻转，并支持中文、英文和常用 Markdown 术语筛选。菜单不显示图标或说明，固定分组排序，一次最多显示 8 个选项。

## 命令范围

- 结构：一级标题、二级标题、三级标题
- 列表：无序列表、有序列表、待办列表、引用
- 内容：提示块、代码块、分隔线
- 丰富内容：表格、图片、Mermaid 图表

每个命令都有一个稳定英文输入：`/h1`、`/h2`、`/h3`、`/bullet_list`、`/ordered_list`、`/task_list`、`/quote`、`/callout`、`/code`、`/divider`、`/table`、`/image`、`/mermaid`。命令不接受空格写法；也可输入拼音缩写，如 `/dmk`、`/yxlb`。中文显示名继续可直接筛选，例如 `/代码块`、`/有序列表`。

提示块默认使用“札记”类型。代码块不要求预选语言，创建后可在右上角透明无边框文本框直接填写或清空语言；空值显示 `text` 占位但不写入 Markdown，聚焦时只显示文本光标。Mermaid 会创建语言为 `mermaid` 的代码块，也可通过同一文本框修改。块公式不在菜单中，因为当前块公式渲染节点不提供原地编辑光标。

## 触发与退出

- 仅在原地写作模式的任意合格空段落首字符为 `/` 时触发。
- 列表项、代码块、表格单元格、块公式、普通正文中的 `/` 和源码编辑模式不触发。
- 引用和提示块中的合法空段落可以触发，插入结果保留在原容器中。
- `↑` / `↓` 移动高亮项，`Enter` / `Tab` 执行，`Esc` 关闭并保留已输入的查询。
- 中文输入法组词期间，候选确认键不会执行命令。
- 空代码块或空 Mermaid 块可用 `Backspace` / `Delete` 移除容器并恢复为普通正文。
- 代码块或 Mermaid 位于父容器末尾时，可从内容末尾按 `→`，或从最后一个视觉行按 `↓`，进入块后的普通正文。

## 表格与图片

表格命令会展开行列设置面板。默认值为 3 行 × 3 列，第一行是表头；支持 1–20 行和 1–12 列。面板默认显示在菜单右侧，空间不足时翻到左侧。面板内使用 `←` / `→` 减少或增加当前数字，使用 `↑` / `↓` 或 `Tab` 在行、列数字容器间切换。

图片命令打开原生 macOS 单图选择器。选中的图片会在后台读取，并通过现有附件存储收纳到发起请求的笔记目录，再以相对 Markdown 图片引用插入。取消选择不会留下占位文字；读取或写入失败会保留 `/image` 并显示错误，切换笔记后返回的旧选择结果会被丢弃。一次撤销会移除图片引用，但不会删除已经收纳的附件文件。

## 技术实现

菜单复用项目现有 `@milkdown/kit` 中的 `slashFactory` 与 `SlashProvider`，撤销栈使用同一依赖提供的 `history` 和 `closeHistory`，代码块退出使用 ProseMirror `exitCode`。这些 API 直接复用编辑器状态、schema 与事务模型，比自行维护浮层触发器、节点替换和撤销栈更可靠。

本功能不新增 npm 包。运行 `nvm use` 切换到 `.nvmrc` 验证过的 Node.js 22 后，通过 `swift run WeiBeiDevTool prepare web-editor` 校验 Node 主版本、锁文件和已安装依赖，并生成应用内使用的浏览器资源；日常入口使用仓库根目录的 Makefile。
