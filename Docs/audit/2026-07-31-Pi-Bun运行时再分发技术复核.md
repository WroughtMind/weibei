# Pi 0.82.1 / Bun 1.3.14 运行时再分发技术复核

复核日期：2026-07-31

魏碑基线：`afb05f07fd4b73a818eb2c4eed191a0a04a6301a`

复核范围：魏碑实际打包的 Pi 单文件运行时、其固定构建输入、Bun 运行时和上游发布的运行时依赖锁。

边界：这是技术取证，不是法律意见，也不代表发布批准。

## 结论

**G0.4 的 Pi / Bun 再分发复核当前不能标记为完成。**

Pi 版本、源码提交、双架构官方归档及 SHA-256 已经闭合；Pi 上游发布的 140 个运行时锁定包也没有未知许可证表达式或声明冲突。但 Pi 的可执行文件由 Bun 1.3.14 编译为单文件，Bun 官方许可证明确说明它静态链接 LGPL-2 的 JavaScriptCore / WebKit、LGPL-2.1 的 tinycc，以及多种其他许可证的库，并特别说明静态链接场景需要提供允许用户修改并重新链接的对象材料。

魏碑当前只随 PiRuntime 放入 Pi 的 MIT 文本和一份概述，没有 Bun 1.3.14 的完整许可证材料、对应静态链接组件的通知，也没有对象文件或其他可验证的重新链接材料。因此：

- 不设置或建议设置 `WEIBEI_PI_REDISTRIBUTION_REVIEWED=1`；
- 不把本报告解释为“允许发布”或“禁止发布”的法律结论；
- 在补齐材料并由发布负责人完成再分发判断前，正式公证包仍应被现有发布门禁拦住。

Pi 源码根许可证是 MIT，魏碑保存的 `Vendor/PiRuntime/LICENSE` 与其正文一致，仅多一个末尾换行。

## Bun 单文件运行时

Bun 1.3.14 的[官方许可证文件](https://github.com/oven-sh/bun/blob/bun-v1.3.14/LICENSE.md)明确写明：

1. Bun 自身为 MIT；
2. Bun 静态链接 JavaScriptCore / WebKit（LGPL-2）；
3. 对静态链接的 LGPL 库，需要提供允许用户修改该库并重新链接应用的对象格式材料；
4. Bun 还静态链接 tinycc（LGPL-2.1）及下列库。

## 当前缺口

| 缺口 | 当前证据 | 关闭条件 |
| --- | --- | --- |
| Bun 许可证未进入 PiRuntime | 魏碑只复制 Pi MIT 与现有概述 Notice | 保存与 Bun 1.3.14 精确对应的官方许可证材料，并验证最终 App 中可见 |
| LGPL 静态链接材料未闭合 | Bun 官方许可证明确提出对象格式 / 重新链接要求 | 发布负责人取得并核实与实际 Bun 1.3.14 二进制对应的对象、源码与重链接材料，或采用经复核的其他分发方式 |
| Bun 静态依赖通知不完整 | 当前 Notice 未列 Bun 的静态依赖和许可证 | 生成并随包保存与固定 Bun 版本一致的完整通知 |
| npm 包完整通知未闭合 | 锁文件声明完整，但 14 个已安装包顶层无独立许可证文件 | 从各项目官方仓库取得相应版权 / 许可证文本并固定来源，或由发布负责人确认可接受的聚合方式 |
| Bun / Pi 构建对应关系只固定到版本和上游脚本 | Pi Release 资产哈希已固定；Bun 版本由上游工作流固定 | 后续生成器同时锁定 Pi 提交、Pi 资产哈希、Bun 标签和 Bun 许可证文件哈希 |

## 本轮没有做的事

- 没有设置任何“已审查 / 可发布”开关；
- 没有上传安装包、创建 Release、签名或公证；
- 没有把许可证声明推导成法律结论；
- 没有修改现有发布门禁；
- 没有因为发现缺口就改变或删除当前 Pi 运行时能力。

## 复现命令

先按 `Vendor/PiRuntime/license-review-inputs.json` 中的官方 URL 下载 Pi 安装锁和 Bun 许可证，再执行：

```bash
node script/check_pi_runtime_license_report.mjs \
  --pi-lock /path/to/pi-coding-agent-install-package-lock.json \
  --bun-license /path/to/bun-1.3.14-LICENSE.md \
  --self-check
```

脚本会验证两份输入的 SHA-256、Pi 固定版本与提交、仓库清单和报告中的双架构归档名 / 哈希一致、140 个包在正确许可证分组中完整且不重复、Bun LGPL 关键事实，以及报告仍保持 `blocked`。它不会下载或复算双架构归档，不会联网、生成批准状态或设置发布环境变量。
