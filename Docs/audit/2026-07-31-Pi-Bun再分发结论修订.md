# Pi / Bun 再分发结论修订（2026-07-31）

> **历史文档(2026-07 Pi 技术调研存档)。** Pi 运行时已于 2026-08-22 整体退役,魏碑唯一 Agent 后端为 NativeAgentRuntime(Sources/WeiBeiCore/NativeAgentRuntime/)。本文结论已过时,仅作决策过程存档,不代表现状。

## 背景

较早的 `2026-07-31-Pi-Bun运行时再分发技术复核.md` 将 G0.4 标为 **blocked**，强调
Bun 静态链接 LGPL 时「对象/重链材料」难以自备。随后产品确认：

- 安装包优先 **体积** 与 **开箱 Agent**；
- 采用 **Bun 单文件 pi** 为默认嵌入；
- 合规叙事改为：**全链路源码公开 + 完整声明 + 工程门禁由人确认**，而非永久禁发。

本文件 **修订** 对外/对内可用的结论；旧文保留为历史取证，不再作为「禁止 DMG」的唯一依据。

## 修订结论

1. **可以**在声明齐全的前提下，将上游 Bun compile 的 standalone `pi` 嵌入社区/正式安装包。  
2. **不是**「零法律风险」；是开源项目常见的 **披露 + 可重建路径 + 发布负责人确认**。  
3. 仓库变量 `WEIBEI_PI_REDISTRIBUTION_REVIEWED=1` 仅为 **工程门禁**（人看过声明后允许跑 `build_release_dmg.sh`），**不是**法律认证。  
4. WeiBei **源码仍 MIT**；安装包须写明第三方，禁止宣称「整包纯 MIT」。

## 合规叙事（摘要）

- Pi：MIT，源码与 pin 提交公开。  
- `bin/pi`：上游 `bun build --compile` 产物；版本与 SHA 在 `manifest.json`。  
- Bun：MIT；静态链接 JSC/WebKit（LGPL-2）、tinycc（LGPL-2.1）等，全文见随包 `BUN_LICENSE.md`。  
- 重建路径：公开 Bun 源码与 LICENSE 中的 relink 步骤 + 公开 Pi 源码，可重新 compile 等价二进制。  
- 业界旁证：存在大规模分发 Bun compile 单文件 CLI 的实践（如业界 AI CLI）；旁证 ≠ 判决。
