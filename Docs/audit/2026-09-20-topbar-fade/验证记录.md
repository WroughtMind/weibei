# 顶部栏渐淡：2026-09-22 重新核验

## 结论

已在真实 Mac Catalyst 诊断包中复现会话顶部硬切。原因是会话外层的 SwiftUI `.clipped()`：它生成的 `_UIInheritedView` 从窗口 `y=40pt` 开始裁剪。内部列表虽然延伸到 `y=0`，内容在到达公共遮罩之前已经被裁掉。

本次基线为本机分支 `320f2538`，远端 #22 为 `f53e3a6c`。本机多出的提交只改变首个消息的留白；上述外部裁剪两版均存在。诊断包只加载独立合成文字，未使用正式工作区或模型服务。
