# 魏碑旧富回答运行时硬规则审计（历史）

状态：旧协议审计已结束；其中面向模型生成的规则已被替代

旧审计围绕能力目录、T1/T2、`evidenceLedger`、当前来源许可和旧富回答提交协议展开。这些不再是当前生成式界面的运行规则。

当前模型生成只遵循唯一 `visualize` Skill。魏碑宿主只守两个真边界：

1. 动态页面不得联网或读取本机文件。
2. 写笔记、改文件、发消息等真实副作用必须先由用户确认。

普通回答与视觉可以使用对话、用户输入、通用知识、示例或课程材料；没有来源不能阻止生成。只有显式归因时核验真实性，显式使用本机素材时核验授权。

历史 renderer 的解析、资源预算与安全检查可以继续保护已保存消息，但不得反向要求模型恢复旧目录、旧 Schema、来源账本或固定题型规则。当前决策见[《魏碑沿 Visualize 技术路线自建生成式界面》](生成式界面基础与Visualize借鉴.md)。
