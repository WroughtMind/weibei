# 魏碑生成式界面：统一使用 dshGenUI

魏碑的生成式界面已切换到 dshGenUI。旧 Visualize 生成规则、手写组件渲染器和独立数学解释器已删除；公式推演、排序练习、配对、归类与过程模拟五类独有组件退役。

## 实现来源

- 组件、规格校验、样式与交互来自 `@changfenhuang/dsh-genui/embed`，不在魏碑复制组件源码。
- Mermaid、ECharts 和 Three.js 引擎与组件一起构建并随 App 打包。
- `genui` 技能由同一依赖包的技能正文生成；魏碑只补原生交付通道说明。
- 模型调用 `render_ui`，通过稳定 id 将界面插入当前回答或原位更新；旧 `weibei_visualize` 不再注册。

## 魏碑接入层

魏碑提供主题设计变量、自然内容高度、当前会话动作回传与原生状态保存。模型只能描述受控组件，不能提交任意 HTML 或 JavaScript。图表引擎从安装包加载；外部图片、音视频与用户点击的链接按组件的地址规则处理。

组件使用 dshGenUI 自身的数量、字段和资源上限。历史界面数据仍留在原消息中，使用新渲染器读取；已退役的节点不再渲染，不保留旧实现或转换分支。

## 构建

运行 `npm run build:genui` 更新打包资源和生成指引，运行 `npm run typecheck:genui` 检查接入代码。正式构建入口会自动生成这些资源。修改只需验证受影响的渲染、动作与宿主接入；不另设学习场景验收矩阵。
