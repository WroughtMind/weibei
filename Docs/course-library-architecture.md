# 课程抽屉与关系台实现说明

## 目标

- 沉浸学习时，用临时课程抽屉完成低频的课程、资料和笔记切换，不挤压或重建 DOC / CHAT / NOTES。
- 进入管理关系后，用开放关系纸面查看和编辑资料与笔记的长期多对多关系。
- 数据很多时先按课程、未归属或未关联范围收窄；搜索和聚焦始终保留命中节点与一跳关系。

## 数据边界

- `Course` 是真实课程实体，不再把全部导入资料假装成一门课程。
- `CourseItemMembership` 保存课程与资料、笔记的归属；同一项目可以属于多门课程。
- `NoteSourceLink` 继续只表示笔记与资料的长期关系，不承担课程归属、当前打开状态或 Agent 查询范围。
- 现有未归属项目进入“未归属”虚拟组，不自动伪造课程。
- 课程文件夹导入时，每个根文件夹创建或复用一门课程，并把本次导入项目加入该课程。
- 学习会话第一版继续放在“学习记录”；不把会话直接画成资料—笔记关系带。

## 界面边界

### 小抽屉

- 直接复用原课程目录的标题、搜索框、行样式与纸面质感，只把打开方式改为覆盖在稳定工作区上方、宽度保持原来约 292pt 的临时抽屉。
- 根层显示课程、独立资料、独立笔记和原有内置示例；“资料关系台”作为明确的长期关系管理入口。
- 点击课程后，资料与笔记直接嵌套展开在课程行下方，并用缩进、分组标题和纵向引导线表达父子层级。
- 打开资料或笔记不重建稳定面板，并立即收起抽屉；点击遮罩、按下 Esc 或再次点击入口也可关闭。

### 大关系台

- 使用一张连续纸面，不使用左右硬侧边栏。
- 文件和笔记是独立节点；关系带直接连接节点。
- 大窗口不再保留含糊的“概览”；它只管理资料与笔记的长期多对多关系，课程归属仍在小抽屉管理。
- 单条关系以克制的低亮度带状曲线呈现，并叠加纸雾；同一节点的多条关系在端点扇出、汇流，不伪造汇总关系。
- 选中一端时，关联节点和关系带一起显影，其余内容退入纸雾。
- 查看模式不显示连接点；管理模式在资料和笔记节点旁显示加号，依次点击两侧加号即可建立关系，同时保留拖拽和删除关系。
- 纸面支持减号、百分比、加号、适合窗口和触控板捏合缩放；缩放后仍可双向滚动浏览。
- 可切换课程、全部、未归属和未关联范围；高密度时优先保留选中项、搜索命中项、一跳节点和高关系节点，并明确显示隐藏数量。

## 共享文件占用

本任务计划占用以下共享核心文件：

- `Sources/WeiBei/Stores/WorkspaceStore.swift`：课程实体、归属、导入和打开动作。
- `Sources/WeiBei/Views/ContentView.swift`：在稳定面板树上方挂载临时课程抽屉。
- `Sources/WeiBei/Views/CourseWorkspaceView.swift`：关系台入口、筛选和聚焦状态。
- `Sources/WeiBeiSelfCheck/SelfChecks.swift`：数据迁移、抽屉挂载和关系台结构自检。

预计释放条件：课程数据可向后兼容保存；小抽屉不重建稳定面板；关系台可查看、建立和删除真实关系；构建、自检和隔离数据真实窗口验收完成。

## 验收

- 旧 `workspace.json` 可直接打开，原资料、笔记、关系和学习会话不丢失。
- 打开、关闭抽屉以及在抽屉中切换资料或笔记时，DOC / CHAT / NOTES 连续性不变。
- 关系台在高密度数据下仍可聚焦和筛选，不渲染不存在的关系组合。
- 拖拽成功后只保存一次；取消拖拽不写盘。
- 使用隔离演示数据完成真实窗口截图，不触碰用户正在使用的课程数据。

## 已完成验证

- 兼容 macOS 15.4 SDK 的完整构建通过。
- `WeiBeiSelfCheck` 完整自检通过，覆盖旧数据兼容、多课程归属、原抽屉动画、树状展开、点击连线、缩放回位和关系带扇出。
- 隔离工作区课程流程验证通过：资料与笔记跳转、重启后持久化、稳定面板不重建均通过。
- 画中画真实操作验证通过：点击“复习问题”与“期末复习笔记”的加号后，可见关系从 17 条准确增加到 18 条，磁盘只新增一条对应关系。
- 画中画缩放验证通过：从 100% 缩小到 80%，再点“适合”回到 62% 并回到纸面起点；课程抽屉也已真实展开到资料、笔记两层。
